# Brief สำหรับ Cowork: สร้าง art ของเกม 25d แล้ววางลงโฟลเดอร์โปรเจกต์โดยตรง

> ส่งไฟล์นี้ให้ Cowork ทั้งไฟล์ หรือวางข้อความด้านล่างสุด ("ข้อความสั่ง Cowork") ก็ได้

## ที่อยู่โปรเจกต์บนเครื่องนี้
- โฟลเดอร์โปรเจกต์: `G:\dev\25d`
- วาง art ที่: `G:\dev\25d\assets\art\props\` และ `G:\dev\25d\assets\art\characters\<ชื่อ>\`
- **ชื่อไฟล์ต้องตรงตามตารางด้านล่างเป๊ะ** (snake_case, นามสกุล `.png`) เกมหยิบใช้ตามชื่ออัตโนมัติ ไม่ต้องแก้โค้ด
- ตอนนี้แต่ละชื่อมีไฟล์ `.svg` (ภาพ vector ชั่วคราว) อยู่แล้ว → **เมื่อวาง `.png` ชื่อเดียวกัน ให้ลบ `.svg` ชื่อนั้นออก** (ถ้ามีทั้งคู่ เกมจะใช้ .svg)
- เสร็จแล้วตรวจในเกม: เปิด PowerShell ที่ `G:\dev\25d` รัน
  `powershell -ExecutionPolicy Bypass -File tools\run.ps1` (คลิกพื้นเพื่อเดิน คลิกของเพื่อใช้)
- จากนั้น commit: `git add assets/art && git -c user.name=drums55 -c user.email=drums55@gmail.com commit -m "art: <ชื่อชิ้น>" && git push`

## สไตล์ (ทุกชิ้นต้องเหมือนกัน)
- **ธีม: ถนนกรุงเทพฯ + steampunk** ของจริงแบบไทย (ตุ๊กตุ๊ก รถเข็นก๋วยเตี๋ยว ศาลพระภูมิ เสาไฟสายรุงรัง เก้าอี้พลาสติก)
  ดัดแปลงด้วยทองเหลือง/ทองแดง ท่อไอน้ำ เกจวัดแรงดัน หมุดย้ำ เฟือง
- **ลุคภาพ: hand-painted 2D แบบเกม Hades (Supergiant)** รูปทรงชัด ขอบเข้ม แสงจากบนซ้าย มีไฮไลต์ขอบ (rim light) และเงาในตัว
  ไม่ใช่ pixel art ไม่ใช่ 3D render ไม่ใช่ flat vector
- **มุมกล้อง: isometric 2:1 มองจากด้านบน ~30°** ทุกชิ้นมุมเดียวกัน ด้านหน้าของวัตถุหันมาทาง "ล่างซ้าย" ของภาพ
- **พื้นหลังโปร่งใส** (PNG RGBA) ไม่มีพื้น ไม่มีตัวหนังสือ ไม่มีลายน้ำ; **ใส่เงาพื้นจางๆ ใต้ฐานในภาพเอง** (เกมไม่วาดเงาให้) เป็นวงรีดำโปร่ง ~38% กว้าง ≈ (ฐานกว้าง+ฐานลึก)/2 × 192 px
- สี: ทองเหลือง `#C9A04A`, ทองแดง `#A8653D`, เขียวสนิม `#3F7A74`, มิ้นต์ตึกแถว `#5E8F86`, แดงพริก `#C0392B`, เขม่า `#2B2629`

## กติกาขนาดและตำแหน่ง (สำคัญ ไม่งั้นภาพลอย/จม)
- ภาพวาดที่ **2 เท่า** ของขนาดในเกม (เกมย่อครึ่ง) ขนาดอ้างอิง: 1 ช่องพื้น = 256×128 px ในภาพ (128×64 ในเกม)
- **Prop:** จุดที่วัตถุแตะพื้น (กลางฐาน) ต้องอยู่ที่ `x = กลางภาพ`, `y = ความสูงภาพ − 160 px`
  คือ **ต้องเหลือพื้นที่โปร่งใส 160 px ใต้จุดกลางฐาน** เสมอ (ไว้ให้มุมหน้า/ล้อที่ยื่นต่ำกว่าจุดกลาง)
  วิธีง่ายสุด: วาดวัตถุให้มุมล่างสุดของมันอยู่เหนือขอบล่างภาพ ~80 px แล้ว crop ให้กลางฐานอยู่กลางภาพแนวนอน
- **ตัวละคร:** แยกชิ้นเป็น cut-out (ดูหัวข้อถัดไป)

## ตัวละคร (cut-out, ไฟล์ไป `assets\art\characters\<ชื่อ>\`)
ตัวละครไม่ใช่ภาพเดียว แต่แยก **6 ชิ้น** ที่เกมเอามาต่อและขยับเอง ทุกชิ้น PNG โปร่งใส ตัวละคร**หันขวา** (มุม 3/4 ไปทางขวา) ตัวเต็มสูง ~340 px ที่ 2 เท่า
แสงจากบนซ้าย สไตล์เดียวกับ prop ต้องวาดจาก "ตัวละครเดียวกัน" ให้สีและสัดส่วนตรงกันทุกชิ้น (ทำเป็นภาพเต็มตัวก่อนแล้วค่อยตัดแยกชิ้นเป็นวิธีที่ดีที่สุด)

| ไฟล์ | ขนาด (px) | เนื้อหา | จุดต่อ (pivot) |
|---|---|---|---|
| `head.png` | 100×120 | หัว+คอ | คอ = กลางล่างของภาพ |
| `torso.png` | 110×130 | อก+ท้องถึงสะโพก | สะโพก = กลางล่างของภาพ |
| `arm_l.png` | 40×112 | แขนซ้ายทั้งท่อน+มือ (แขนไกล) | หัวไหล่ = กลางบนของภาพ |
| `arm_r.png` | 60×180 | แขนขวา+มือ (ถืออาวุธ/ของ ถ้ามี) | หัวไหล่ = กลางบน |
| `leg_l.png` | 44×136 | ขาซ้าย+รองเท้า | ข้อสะโพก = กลางบน |

ถ้า pivot ไม่ตรงกติกา ให้วาง `pivots.json` ไว้ในโฟลเดอร์เดียวกัน: `{"head":[50,118],"arm_r":[30,6]}` (พิกัด px ในภาพ)
