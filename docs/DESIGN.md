## 1. เกมนี้คืออะไร (ประโยคเดียว)
**เกมผจญภัย point-and-click มุม isometric ที่คุณเป็นไรเดอร์ส่งของในย่านกรุงเทพฯ ยุคไอน้ำ ต้องเลือกว่าจะส่งของให้ใคร ในเวลาที่มีจำกัด แล้วการเลือกนั้นเปลี่ยนย่านและเรื่องราว**

สิ่งที่ทำให้ไม่ linear: **แต่ละวันมีงานให้เลือกมากกว่าที่ทำได้** งานไหนรับ งานไหนทิ้ง ส่งให้ใครก่อน และ "เปิดกล่องดูไหม" คือตัวเลือกของผู้เล่น ไม่ใช่ลำดับที่เราวางให้

## 2. เสาหลัก 3 ต้น (ใช้ตัดสินทุกฟีเจอร์ — ถ้าไม่หนุนสักต้น ไม่ทำ)
1. **ย่านมีชีวิต** — คนในย่านจำเราได้ มีความสัมพันธ์ (ชื่อเสียง) มีช่วงเวลาของวัน ร้านเปิด-ปิด เหตุการณ์เปลี่ยนตามสิ่งที่เราทำ
2. **ส่งของ = เลือก** — เวลาและที่เก็บของจำกัด งานขัดกัน ของบางชิ้นมีความลับ การเลือกมีผลยาว (เงิน vs ชื่อเสียง vs ความจริง)
3. **สตรีทไทย × ไอน้ำ ต้องรู้สึกจริง** — ของทุกชิ้นคือของจริงบนถนนไทยที่ถูกดัดแปลง ไม่ใช่ fantasy ลอยๆ (ตุ๊กตุ๊ก วินฯ ศาลพระภูมิ สายไฟ)

## 3. Core loop (1 วันในเกม ≈ 8–12 นาทีจริง)
```
เช้า: ไป "วินฯ" (บอร์ดงาน) → เห็นงาน 3–5 งาน (ผู้ว่าจ้าง, ของ, ปลายทาง, ค่าจ้าง, เส้นตาย, ความเสี่ยง)
     → รับได้ไม่เกินช่องเก็บของ (เริ่ม 2) → เลือก
กลางวัน: วิ่งงานข้ามเขต (ห้อง) → อุปสรรค: หุ่นรวน / ด่านตรวจของบริษัทไอน้ำ / ทางลัดที่ต้องซ่อม
     → ส่งของ (ทันเวลา = เต็ม, สาย = ลด, ไม่ส่ง = เสียชื่อ) → ระหว่างทางเจอ "งานแทรก" (คนขอความช่วยเหลือ)
เย็น: กลับซอย → จ่ายหนี้/อัปเกรดรถ/ซ่อมของ → ฉากเรื่อง (ตามชื่อเสียงและสิ่งที่เลือก) → บันทึก → วันใหม่
```
ตัวนับ: **เงิน** (หนี้ → ทุน), **ชื่อเสียง** 3 ฝ่าย, **เวลาในวัน** (นาฬิกาไอน้ำ 6 ช่วง), **ช่องเก็บของ** บนรถ

## 4. โครงโลก (hub + เขต) — เปิดทีละเขตตามเรื่อง ไม่บังคับลำดับงานในเขต
| เขต (ห้อง) | บทบาท | สถานะ |
|---|---|---|
| ซอยทองเหลือง (hub) | วินฯ+บอร์ดงาน, ลุงประดิษฐ์ (ช่าง/ที่ปรึกษา), ศาล, ที่จอดรถ | มีแล้ว (ต้องเพิ่มบอร์ดงาน) |
| ตลาดไอน้ำ | ของ/อะไหล่/ข่าวลือ, เจ๊หมวย, หม้อไอน้ำตลาด | มีแล้ว |
| อู่ไอน้ำเฮียเป้ง | อัปเกรด/ซ่อมรถ, เจ้าหนี้→พันธมิตร, งานเสี่ยง | มีแล้ว (เฮียยังไม่มี sprite จริง) |
| ท่าเรือคลอง | ของผิดกฎหมาย? เรือหางยาวไอน้ำ, ฝ่ายคนคลอง | บทที่ 2 |
| สำนักงานบริษัทไอน้ำกรุงเทพฯ | ฝ่าย "ทางการ": งานเงินดี แต่ทำร้ายย่าน, ด่านตรวจ | บทที่ 2 |
| หลังคาตึกแถว / ทางลัด | เส้นทางลัดที่ต้องปลดล็อกด้วยการซ่อม/อัปเกรด | บทที่ 2–3 |
| โรงหม้อไอน้ำกลาง | ฉากจบ: ใครควบคุมไอน้ำของย่าน | บทที่ 3 |

## 5. ระบบ (เรียงตามลำดับที่ควรทำ)
1. **งานแบบ data-driven (`assets/jobs/*.json`)** — งาน = {ผู้ว่าจ้าง, จุดรับ, จุดส่ง, ค่าจ้าง, เส้นตาย(ช่วงเวลา), ชื่อเสียง±ต่อฝ่าย, เงื่อนไขเปิด, ความลับของของ} + **บอร์ดงาน** ที่วินฯ ให้เลือก → นี่คือตัวทำลายความ linear ต้องมาก่อน
2. **เวลาในวัน** — 6 ช่วง (เช้า/สาย/เที่ยง/บ่าย/เย็น/ค่ำ) เดินไปเมื่อเปลี่ยนห้อง/ส่งงาน ร้าน-NPC-ศัตรูต่างกันตามช่วง (ตอนค่ำหุ่นดุขึ้น) ภาพฉากเปลี่ยนโทนแสง (modulate ไม่ต้องวาดใหม่)
3. **ชื่อเสียง 3 ฝ่าย** — ชาวบ้าน / อู่-เฮียเป้ง / บริษัทไอน้ำ ส่งผล: ราคางาน, บทพูด, ด่านตรวจผ่านไหม, ตอนจบ
4. **รถ = ตัวละครที่สอง** — อัปเกรด: ช่องเก็บของ (2→4), เร่งไอน้ำ (วิ่งเร็วชั่วคราว/ชนหุ่น), โคมหน้า (เปิดทางลัดกลางคืน) ซ่อมที่อู่ — ทำให้เงินมีความหมายหลังหมดหนี้
5. **ต่อสู้ให้มีจังหวะ** — ตอนนี้แตะ=ตี ตีจนตาย เพิ่ม: หุ่น 3 แบบ (ไล่ / ยิงไอน้ำระยะไกล / ตัวหนักต้องตีด้านหลัง), ท่าหลบ (แตะพื้นเร็วๆ = พุ่ง), ของในฉากใช้ได้ (วาล์วปล่อยไอน้ำใส่ศัตรู) — ให้ **สมองคิด** ไม่ใช่กดรัว
6. **ของมีความลับ** — บางกล่องเปิดได้ (ได้ความจริง/ของมีค่า แต่เสียชื่อถ้าถูกจับได้) = ตัวเลือกเชิงศีลธรรมแบบเล็กๆ ทุกวัน
7. เมนู/เซฟหลายช่อง, เสียง, การสอนเล่น — ท้ายสุด

## 6. เรื่อง (3 บท) และการเลือก
- **บทที่ 1 — หนี้** (ทำแล้ว แต่จะถูก "ย้อม" ใหม่ให้ผ่านบอร์ดงาน): ปลดหนี้ รู้จักย่าน รู้ว่าเครื่องจักรรวนไม่ใช่เรื่องบังเอิญ
- **บทที่ 2 — ใครแกะวาล์ว**: บริษัทไอน้ำกรุงเทพฯ กำลัง "ซื้อ" ย่านด้วยการทำให้เครื่องเก่ารวน แล้วขายระบบใหม่ งานจากบริษัทให้เงินดี งานจากชาวบ้านให้เงินน้อยแต่ได้ความจริง → ผู้เล่นเลือกเองว่าจะเป็นใคร
- **บทที่ 3 — หม้อไอน้ำกลาง**: 2–3 ตอนจบตามชื่อเสียง (ย่านอยู่รอดแบบเก่า / ย่านกลายเป็นของบริษัท แต่คุณรวย / ทางที่สาม: ลุงประดิษฐ์+เฮียเป้งสร้างระบบของย่านเอง)
- ตัวละครหลัก 5: ไรเดอร์, ลุงประดิษฐ์ (ความทรงจำของย่าน), เจ๊หมวย (ข่าว/การค้า), เฮียเป้ง (เงิน/รถ), **คุณนายวรรณ** ตัวแทนบริษัท (ยังไม่มี) + คนคลอง 1 คน

## 7. ขอบเขตที่ "เล่นแล้วรู้สึกว่าเป็นเกม" (vertical slice) — เป้าหมายถัดไป
- 1 วันเต็ม: บอร์ดงาน 4 งาน รับได้ 2, เส้นตาย, ส่งข้ามเขต 4 เขต (เพิ่มท่าเรือ 1 ห้อง), เย็นมีอัปเกรดรถ 1 อย่าง + ฉากเรื่อง 1 ฉาก
- ศัตรู 2 แบบ, ท่าหลบ 1 ท่า, ด่านตรวจ 1 จุด
- ชื่อเสียง 2 ฝ่ายแสดงผลจริงใน 2 บทพูด + 1 ราคางาน
- เกณฑ์ผ่าน: เล่น 3 วันแล้ว **ผู้เล่น 2 คนเลือกงานไม่เหมือนกัน** และเห็นผลต่างกัน

## 8. ลำดับงาน (milestones)
> M2 เริ่ม 2026-10-01 ด้วย "ของไทยในฉาก" ก่อน (เจ้าของสั่ง): วิน, ตู้โทรศัพท์, ป้ายรถเมล์, หมูปิ้ง, แมวร้านชำ, ยางปลูกต้นไม้
> ท่าเรือคลอง (ห้องที่ 4, เข้าจากผนังขวาของตลาด) + เรือหางยาวไอน้ำ + พี่แจ่ม + งาน 2 งาน เสร็จ 2026-10-01
> งานแบบปริศนา (ของแตกง่าย / ผู้รับย้าย-ผิดคน / ผู้รับขอของเพิ่ม) + 4 งานฮาๆ เสร็จ 2026-10-01
> ชื่อเสียง 3 ฝ่าย (ทิป/เปิดงาน/บทพูด/ส่วนลดค่าเช่า) + คุณนายวรรณกับบูธบริษัทในซอย + งานบริษัท 3 + งานโต้กลับ 1 เสร็จ 2026-10-01
> ตัดการต่อสู้ทิ้ง → หุ่นบริษัทเป็นปริศนา (กรวยสายตา, ย่องดึงฟิวส์จากด้านหลัง, วาล์วไอน้ำ) เสร็จ 2026-10-01
> ยังเหลือใน M2: sprite จริงของคุณนายวรรณ — แต่ดูข้อ 10 ก่อน (ข้อเสนอเปลี่ยนทิศ)
- **M0 (เสร็จ)**: โครง, ภาพ, ตัวละคร, 3 ห้อง, บทที่ 1 แบบ linear
- **M1 — บอร์ดงาน + เวลา** (ระบบ 1–2) **[เสร็จ 2026-10-01]**: jobs.json (6 งาน), UI บอร์ดงาน, ช่องเก็บของ 2, นาฬิกา 6 ช่วง + นอน,
  ส่งสายได้เงินน้อยลง, แสงเปลี่ยนตามเวลา. ยังขาดในเกณฑ์ M1: งานแบบปริศนา (ข้อ 4 ของเจ้าของ) และของ BKK ในฉาก (ข้อ 5) → ทำใน M2
- **M2 — ย่านตอบสนอง** (ระบบ 3 + ท่าเรือ + คุณนายวรรณ): ชื่อเสียง, งานบริษัท vs ชาวบ้าน, ด่านตรวจ
- **M3 — รถและการต่อสู้** (ระบบ 4–5): อัปเกรด, ศัตรู 3 แบบ, หลบ
- **M4 — vertical slice ครบ** + เมนู/เซฟ/เสียง → ให้คนอื่นลองเล่น
- หลังจากนั้นค่อยทำบทที่ 2–3 เต็ม

## 9. คำตอบจากเจ้าของ (2026-10-01) **[ตัดสินใจแล้ว]**
1. **สั้น** — ทำเวอร์ชันสั้นจบได้ (เป้า 2–3 ชม., ~5–7 วันในเกม) ลองก่อน ค่อยขยาย
2. **ตลก** — โทนละครซอย ตัวละครปากจัด สถานการณ์เพี้ยนๆ บริษัทไอน้ำเป็นตัวร้ายแบบน่าหมั่นไส้ ไม่โหด
3. **การเลือกกลางๆ** — เปลี่ยนบทพูด ราคา งานที่เปิด และฉากจบ; ไม่ถึงขั้นร้านปิดถาวร/ตัวละครหาย
4. **เน้นปริศนา** — ต่อสู้เป็นส่วนน้อย: หุ่นรวน = อุปสรรคที่ "แก้" ได้ (ปิดวาล์ว ล่อด้วยของ หาทางอ้อม) มากกว่าตีจนตาย;
   งานส่งของควรมีปมให้คิด (ของแตกง่าย ต้องส่งก่อนร้อน / ต้องหาคนรับที่ย้ายที่ / ของผิดกล่อง)
5. **ฉากต้อง "เก๊ต" ว่าเป็นกรุงเทพฯ** — ทุกห้องต้องมีของที่มีแค่ที่นี่: วินมอเตอร์ไซค์+เสื้อกั๊ก, สายไฟพันเสา, รถเข็นก๋วยเตี๋ยว,
   ศาลพระภูมิ, แผงลอยริมทาง, ป้ายรถเมล์, ตู้โทรศัพท์, คลอง+เรือหางยาว, แมวร้านชำ, ป้ายรถตุ๊กตุ๊ก, ฝาท่อ กทม.
   → เพิ่มเป็นเกณฑ์ตรวจทุกห้อง: "ถ้าลบป้ายชื่อห้องออก ยังรู้ไหมว่านี่กรุงเทพฯ"

## 10. ร่าง 2 — "ไรเดอร์ห้าดาว" : rider vs platform vs ลูกค้า (เจ้าของ 2026-10-01) **[ตัดสินใจแล้ว — กทม. ปัจจุบัน]**
> **P0 เสร็จ 2026-10-01** (ดู 10.8). ข้อ 1–9 ด้านบน = แผนเวอร์ชันย่านตายตัว (เก็บไว้เป็นประวัติ)
> ร่าง 2 แทนข้อ 1–8: ยุบ "ย่าน" ตายตัว + บอร์ดงาน + เนื้อเรื่อง 3 บท → เมืองสุ่ม + แอปไรเดอร์ + เอาตัวรอดรายวัน
> เจ้าของ: "ยุบย่าน ทำ random gen", "ใช้ app แทน board", "map ของ BKK", "งานซ้อน", "evil corp → platform",
> "อาหาร vs เอกสาร/พัสดุ behavior ต่างกัน", "goal วิ่งงาน เก็บเงิน ค่าเช่ารถ ค่าใช้จ่าย ค่าน้ำมัน", "ทั้ง serious ทั้ง absurd",
> "มีสิทธิ viral เพราะ rider/ลูกค้าจริงเข้าใจปัญหา", ปัญหาตั้งต้น: หนี้นอกระบบ (หนีเจ้าหนี้), platform โหด, ปักหมุดไม่ตรง, รีวิว 1 ดาว

### 10.1 ประโยคเดียว
ไรเดอร์ติดหนี้ดอกลอย วิ่งงานในกรุงเทพฯ ที่สุ่มใหม่ทุกเกม ผ่านแอปที่ลดค่ารอบเมื่อไหร่ก็ได้ ส่งให้ลูกค้าที่ปักหมุดผิดแล้วให้หนึ่งดาว
— ต้องอยู่รอดให้ครบ N วันโดยบัญชีไม่โดนปิด รถไม่โดนยึด และหนีเจ้าหนี้ให้พ้น

### 10.2 Loop รายวัน
```
เช้า   : จ่ายค่าเช่ารถ/ผ่อนรถ + ดอกรายวัน (ไม่จ่าย = เจ้าหนี้ตามหา) → เปิดแอป "ออนไลน์" → ประกาศนโยบายประจำวัน
วิ่งงาน: ออเดอร์เด้ง (นับถอยหลังกดรับ, ปฏิเสธบ่อย = อัตรารับงานตก) → แผนที่: เลือกเส้นทางไปจุดรับ (เวลา+น้ำมัน+เสี่ยง)
         → ลงที่สถานที่ (ฉาก iso สุ่มตามประเภท) → ปัญหาเฉพาะที่ → รับของ → วิ่งไปส่ง → ปัญหาปลายทาง → ดาว + ทิป
ค่ำ    : สรุปรายรับ-รายจ่ายจริงจัง (แบบสลิป) → นอน (หรือวิ่งต่อแลกความล้า)
```
เป้า (เกมสั้น 5–7 วัน): ปลดเงินต้นหนี้นอกระบบ หรืออย่างน้อยรอด — แพ้เมื่อ บัญชีโดนปิด (เรตติ้งต่ำ) / รถโดนยึด / หมดตัว

### 10.3 เมืองสุ่ม (random gen) — สถานที่ = ประเภท × ตัวแปร
ทุกเกมสุ่มแผนที่ (กราฟจุด ~12–20 จุด ชื่อซอยสุ่มสไตล์ "สุขุมวิท 101/1 แยก 3") แต่ละจุดเป็นประเภทหนึ่ง แล้วสร้างฉากจาก template ของประเภทนั้น + prop สุ่ม
| ประเภท | ปัญหา/ปริศนาประจำที่ |
|---|---|
| ตลาด (หลายร้าน อาหาร+ของ) | หาร้านให้เจอในแผงที่หน้าตาเหมือนกัน, คนแน่น, ที่จอดไม่มี |
| ร้านอาหาร | คิวรอนาน (รอ vs ยกเลิก), ร้านทำผิดเมนู, ร้านปิดแต่แอปบอกเปิด |
| บ้าน/หมู่บ้าน | หมาไล่ (stealth แบบหุ่นเดิม), บ้านเลขที่ไม่เรียง, ปักหมุดกลางหมู่บ้าน |
| คอนโด | รปภ. ไม่ให้ขึ้น, ต้องใช้ลิฟต์ขนของ/ถอดแจ็กเก็ต, ลูกค้าไม่ยอมลงมา |
| ออฟฟิศ | เอกสารต้องเซ็นโดย "คนที่ถูกต้อง", รีเซปชันส่งต่อชั้น, เส้นตายธนาคารปิด |
| ปั๊มน้ำมัน | เติมน้ำมัน, ห้องน้ำ, จุดพักไรเดอร์ = ข่าวลือ/เตือนภัย |
| อู่ | ซ่อมรถ/ยางแบน, ผ่อนรถ, อัปเกรดกล่อง |
| ฯลฯ | วินฯ, เซเว่น, โรงพยาบาล, วัด, ป้ายรถเมล์, ใต้ทางด่วน |

### 10.4 งานแต่ละแบบ = behavior ต่างกัน
- **อาหาร**: ความร้อนลดตามเวลา (ร้อน→อุ่น→เย็นชืด) มีผลกับดาว, ขี่เร็ว/ทางขรุขระ = หก, น้ำแข็งละลาย, รอร้าน
- **เอกสาร**: ต้องถึงมือคนชื่อนั้น (ตรวจบัตร/ลายเซ็น), เส้นตายแข็ง, ส่งผิดคน = ส่งไม่สำเร็จ
- **พัสดุ**: ขนาดกินช่อง, COD เก็บเงินปลายทาง (ลูกค้าไม่รับ = ไรเดอร์แบกค่าของ), ผู้รับไม่อยู่ = ฝาก รปภ. (เสี่ยงโดนร้องเรียน)
- **งานเพี้ยน** (absurd): ต่อคิวแทน, ส่งแมว, ส่งโอ่ง, ซื้อหวยให้, ไปรับกุญแจที่ลืมไว้
- **งานซ้อน**: รับได้ 2–3 พร้อมกัน แอปชอบยัดงานซ้อนทางตรงข้ามกัน

### 10.5 ปัญหาจริง → กลไก (ค้นมา 2026-10-01)
- ค่ารอบโดนลดโดยแจ้งล่วงหน้าวันเดียว ไม่มีคำอธิบาย (ค่ารอบเริ่มต้นเคยราว 60 บาท ปี 2018 เหลือ 38–40 บาท) → **ประกาศนโยบายรายวัน** เปลี่ยนค่ารอบ/โบนัส
- รายได้ตก (จากราว 2,000 เหลือ 900 บาท/วันในบางวัน), วิ่งหลายแอปสลับกัน → เป้ารายได้รายวันที่ตึงจริง
- ชั่วโมงยาว (ราว 45% ทำเกิน 60 ชม./สัปดาห์), อุบัติเหตุราว 1 ใน 3 เพราะเร่งเวลา/ดูมือถือ → **ความล้า** + เลือก "ขี่เร็ว vs ขี่ปลอดภัย"
- ประกันแค่บางเงื่อนไข จ่ายค่ารักษาเอง → อุบัติเหตุ = ค่าใช้จ่ายก้อน
- อัลกอริทึมจ่ายงานไม่เป็นธรรม/รวน, พ่วงงาน 2–3 งาน → งานซ้อนแปลกๆ, โบนัส "ครบ 20 งาน" ที่งานที่ 20 ไม่ยอมเด้ง
- ลูกค้ายกเลิกหลังซื้อของแล้ว / COD ไม่รับ → ไรเดอร์จ่ายค่าอาหารเอง (เลือกกินเองได้ = absurd)
- ปักหมุดผิด (หมุดกลางหมู่บ้าน) + ลูกค้าไม่รับสาย → ปริศนาหาบ้าน: ถามคนแถวนั้น, ดูเบาะแสในแชท
- ห้าง/คอนโดห้ามใช้ลิฟต์ปกติ ให้ถอดแจ็กเก็ต, ลูกค้าต้องลงมารับ → ฉากคอนโด
- เรตติ้งเอนเข้าข้างลูกค้า, ร้องเรียนไม่มีผล, ปิดบัญชีไม่บอกเหตุผล → **รีวิว 1 ดาว** ที่ไม่ใช่ความผิดเรา + มินิเกมอุทธรณ์กับแชทบอท
- ค่าใช้จ่ายบังคับ (กล่อง/เสื้อ/ค่าสมัคร), น้ำมัน, ค่าเช่ารถ/ผ่อน, แอปปล่อยกู้แล้วหักจากรายได้ → สลิปรายจ่ายรายวัน
- หนี้นอกระบบ "ดอกลอย" (จ่ายแต่ดอก เงินต้นไม่ลด) → ดอกรายวัน + **เจ้าหนี้ตามหา**: โผล่ตามสถานที่ มีกรวยสายตา (ใช้ระบบ PatrolBot เดิม) ต้องหลบ/หนี
- ตำรวจ/เทศกิจ จอดผิดที่, ฝนตก (ค่ารอบพิเศษแต่ลื่น อาหารเปียก), น้ำท่วมเส้นทาง → อีเวนต์บนแผนที่

### 10.6 ตัวเลขที่ต้องติดตาม (แทนชื่อเสียง 3 ฝ่าย)
เงินสด · หนี้ (ต้น/ดอก/ความอดทนเจ้าหนี้) · **เรตติ้งในแอป** (ต่ำ = งานแย่ → ปิดบัญชี) · อัตรารับงาน · น้ำมัน · ความล้า · เพื่อนไรเดอร์/วิน (ช่วยบอกหมุด/เตือนด่าน)

### 10.7 ของเดิมที่ใช้ต่อ / ทิ้ง
ใช้ต่อ: engine/iso/point&click/pathfinding/pick test, Jobs (ปรับเป็น orders), fragile/redirect/needs (= ปักหมุดผิด/คนรับผิด/เงื่อนไขปลายทาง),
PatrolBot (= เจ้าหนี้/หมา/รปภ.), นาฬิกาวัน, ระบบลงสี PNG, ตัวละคร 3D
ทิ้ง/แปลง: บอร์ดงาน → แอป, ประตูระหว่างห้อง → แผนที่, ห้องตายตัว 4 ห้อง → template ต่อประเภท, บริษัทไอน้ำ → แพลตฟอร์ม, เนื้อเรื่อง 3 บท → อีเวนต์+ตอนจบตามผล

### 10.7b ช่วงขี่ (เพิ่ม 2026-10-01 หลังเจ้าของติว่า "คลิกๆ ตาม map ไม่สนุก")

รักษาความนิ่งของอาหาร) → ทักษะการขี่แปลงเป็นเวลา/ดาว. P1 (ปัญหาในสถานที่) ทำต่อหลังเจ้าของลองช่วงขี่
