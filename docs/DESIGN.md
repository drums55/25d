## 1. เกมนี้คืออะไร (ประโยคเดียว)
**เกมผจญภัย point-and-click มุม isometric ที่คุณเป็นไรเดอร์ส่งของในย่านกรุงเทพฯ ยุคไอน้ำ ต้องเลือกว่าจะส่งของให้ใคร ในเวลาที่มีจำกัด แล้วการเลือกนั้นเปลี่ยนย่านและเรื่องราว**

สิ่งที่ทำให้ไม่ linear: **แต่ละวันมีงานให้เลือกมากกว่าที่ทำได้** งานไหนรับ งานไหนทิ้ง ส่งให้ใครก่อน และ "เปิดกล่องดูไหม" คือตัวเลือกของผู้เล่น ไม่ใช่ลำดับที่เราวางให้

## 2. เสาหลัก 3 ต้น (ใช้ตัดสินทุกฟีเจอร์ — ถ้าไม่หนุนสักต้น ไม่ทำ)
1. **ย่านมีชีวิต** — คนในย่านจำเราได้ มีความสัมพันธ์ (ชื่อเสียง) มีช่วงเวลาของวัน ร้านเปิด-ปิด เหตุการณ์เปลี่ยนตามสิ่งที่เราทำ
2. **ส่งของ = เลือก** — เวลาและที่เก็บของจำกัด งานขัดกัน ของบางชิ้นมีความลับ การเลือกมีผลยาว (เงิน vs ชื่อเสียง vs ความจริง)
3. **สตรีทไทย × ไอน้ำ ต้องรู้สึกจริง** — ของทุกชิ้นคือของจริงบนถนนไทยที่ถูกดัดแปลง ไม่ใช่ fantasy ลอยๆ (ตุ๊กตุ๊ก วินฯ ศาลพระภูมิ สายไฟ)

## 3. Core loop (1 วันในเกม ≈ 8–12 นาทีจริง)
```
เช้า: ไป "วินฯ" (บอร์ดงาน) → เห็นงาน 3–5 งาน (ผู้ว่าจ้าง, ของ, ปลายทาง, ค่าจ้าง, เส้นตาย, ความเสี่ยง)
     → รับได้ไม่เกินช่องเก็บของ (เริ่ม 2) → เลือก
กลางวัน: วิ่งงานข้ามเขต (ห้อง) → อุปสรรค: หุ่นรวน / ด่านตรวจของบริษัทไอน้ำ / ทางลัดที่ต้องซ่อม
     → ส่งของ (ทันเวลา = เต็ม, สาย = ลด, ไม่ส่ง = เสียชื่อ) → ระหว่างทางเจอ "งานแทรก" (คนขอความช่วยเหลือ)
เย็น: กลับซอย → จ่ายหนี้/อัปเกรดรถ/ซ่อมของ → ฉากเรื่อง (ตามชื่อเสียงและสิ่งที่เลือก) → บันทึก → วันใหม่
```
ตัวนับ: **เงิน** (หนี้ → ทุน), **ชื่อเสียง** 3 ฝ่าย, **เวลาในวัน** (นาฬิกาไอน้ำ 6 ช่วง), **ช่องเก็บของ** บนรถ

## 4. โครงโลก (hub + เขต) — เปิดทีละเขตตามเรื่อง ไม่บังคับลำดับงานในเขต
| เขต (ห้อง) | บทบาท | สถานะ |
|---|---|---|
| ซอยทองเหลือง (hub) | วินฯ+บอร์ดงาน, ลุงประดิษฐ์ (ช่าง/ที่ปรึกษา), ศาล, ที่จอดรถ | มีแล้ว (ต้องเพิ่มบอร์ดงาน) |
| ตลาดไอน้ำ | ของ/อะไหล่/ข่าวลือ, เจ๊หมวย, หม้อไอน้ำตลาด | มีแล้ว |
| อู่ไอน้ำเฮียเป้ง | อัปเกรด/ซ่อมรถ, เจ้าหนี้→พันธมิตร, งานเสี่ยง | มีแล้ว (เฮียยังไม่มี sprite จริง) |
| ท่าเรือคลอง | ของผิดกฎหมาย? เรือหางยาวไอน้ำ, ฝ่ายคนคลอง | บทที่ 2 |
| สำนักงานบริษัทไอน้ำกรุงเทพฯ | ฝ่าย "ทางการ": งานเงินดี แต่ทำร้ายย่าน, ด่านตรวจ | บทที่ 2 |
| หลังคาตึกแถว / ทางลัด | เส้นทางลัดที่ต้องปลดล็อกด้วยการซ่อม/อัปเกรด | บทที่ 2–3 |
| โรงหม้อไอน้ำกลาง | ฉากจบ: ใครควบคุมไอน้ำของย่าน | บทที่ 3 |

## 5. ระบบ (เรียงตามลำดับที่ควรทำ)
1. **งานแบบ data-driven (`assets/jobs/*.json`)** — งาน = {ผู้ว่าจ้าง, จุดรับ, จุดส่ง, ค่าจ้าง, เส้นตาย(ช่วงเวลา), ชื่อเสียง±ต่อฝ่าย, เงื่อนไขเปิด, ความลับของของ} + **บอร์ดงาน** ที่วินฯ ให้เลือก → นี่คือตัวทำลายความ linear ต้องมาก่อน
2. **เวลาในวัน** — 6 ช่วง (เช้า/สาย/เที่ยง/บ่าย/เย็น/ค่ำ) เดินไปเมื่อเปลี่ยนห้อง/ส่งงาน ร้าน-NPC-ศัตรูต่างกันตามช่วง (ตอนค่ำหุ่นดุขึ้น) ภาพฉากเปลี่ยนโทนแสง (modulate ไม่ต้องวาดใหม่)
3. **ชื่อเสียง 3 ฝ่าย** — ชาวบ้าน / อู่-เฮียเป้ง / บริษัทไอน้ำ ส่งผล: ราคางาน, บทพูด, ด่านตรวจผ่านไหม, ตอนจบ
4. **รถ = ตัวละครที่สอง** — อัปเกรด: ช่องเก็บของ (2→4), เร่งไอน้ำ (วิ่งเร็วชั่วคราว/ชนหุ่น), โคมหน้า (เปิดทางลัดกลางคืน) ซ่อมที่อู่ — ทำให้เงินมีความหมายหลังหมดหนี้
5. **ต่อสู้ให้มีจังหวะ** — ตอนนี้แตะ=ตี ตีจนตาย เพิ่ม: หุ่น 3 แบบ (ไล่ / ยิงไอน้ำระยะไกล / ตัวหนักต้องตีด้านหลัง), ท่าหลบ (แตะพื้นเร็วๆ = พุ่ง), ของในฉากใช้ได้ (วาล์วปล่อยไอน้ำใส่ศัตรู) — ให้ **สมองคิด** ไม่ใช่กดรัว
6. **ของมีความลับ** — บางกล่องเปิดได้ (ได้ความจริง/ของมีค่า แต่เสียชื่อถ้าถูกจับได้) = ตัวเลือกเชิงศีลธรรมแบบเล็กๆ ทุกวัน
7. เมนู/เซฟหลายช่อง, เสียง, การสอนเล่น — ท้ายสุด

## 6. เรื่อง (3 บท) และการเลือก
- **บทที่ 1 — หนี้** (ทำแล้ว แต่จะถูก "ย้อม" ใหม่ให้ผ่านบอร์ดงาน): ปลดหนี้ รู้จักย่าน รู้ว่าเครื่องจักรรวนไม่ใช่เรื่องบังเอิญ
- **บทที่ 2 — ใครแกะวาล์ว**: บริษัทไอน้ำกรุงเทพฯ กำลัง "ซื้อ" ย่านด้วยการทำให้เครื่องเก่ารวน แล้วขายระบบใหม่ งานจากบริษัทให้เงินดี งานจากชาวบ้านให้เงินน้อยแต่ได้ความจริง → ผู้เล่นเลือกเองว่าจะเป็นใคร
- **บทที่ 3 — หม้อไอน้ำกลาง**: 2–3 ตอนจบตามชื่อเสียง (ย่านอยู่รอดแบบเก่า / ย่านกลายเป็นของบริษัท แต่คุณรวย / ทางที่สาม: ลุงประดิษฐ์+เฮียเป้งสร้างระบบของย่านเอง)
- ตัวละครหลัก 5: ไรเดอร์, ลุงประดิษฐ์ (ความทรงจำของย่าน), เจ๊หมวย (ข่าว/การค้า), เฮียเป้ง (เงิน/รถ), **คุณนายวรรณ** ตัวแทนบริษัท (ยังไม่มี) + คนคลอง 1 คน

## 7. ขอบเขตที่ "เล่นแล้วรู้สึกว่าเป็นเกม" (vertical slice) — เป้าหมายถัดไป
- 1 วันเต็ม: บอร์ดงาน 4 งาน รับได้ 2, เส้นตาย, ส่งข้ามเขต 4 เขต (เพิ่มท่าเรือ 1 ห้อง), เย็นมีอัปเกรดรถ 1 อย่าง + ฉากเรื่อง 1 ฉาก
- ศัตรู 2 แบบ, ท่าหลบ 1 ท่า, ด่านตรวจ 1 จุด
- ชื่อเสียง 2 ฝ่ายแสดงผลจริงใน 2 บทพูด + 1 ราคางาน
- เกณฑ์ผ่าน: เล่น 3 วันแล้ว **ผู้เล่น 2 คนเลือกงานไม่เหมือนกัน** และเห็นผลต่างกัน

## 8. ลำดับงาน (milestones)
> M2 เริ่ม 2026-10-01 ด้วย "ของไทยในฉาก" ก่อน (เจ้าของสั่ง): วิน, ตู้โทรศัพท์, ป้ายรถเมล์, หมูปิ้ง, แมวร้านชำ, ยางปลูกต้นไม้
> ท่าเรือคลอง (ห้องที่ 4, เข้าจากผนังขวาของตลาด) + เรือหางยาวไอน้ำ + พี่แจ่ม + งาน 2 งาน เสร็จ 2026-10-01
> งานแบบปริศนา (ของแตกง่าย / ผู้รับย้าย-ผิดคน / ผู้รับขอของเพิ่ม) + 4 งานฮาๆ เสร็จ 2026-10-01
> ชื่อเสียง 3 ฝ่าย (ทิป/เปิดงาน/บทพูด/ส่วนลดค่าเช่า) + คุณนายวรรณกับบูธบริษัทในซอย + งานบริษัท 3 + งานโต้กลับ 1 เสร็จ 2026-10-01
> ตัดการต่อสู้ทิ้ง → หุ่นบริษัทเป็นปริศนา (กรวยสายตา, ย่องดึงฟิวส์จากด้านหลัง, วาล์วไอน้ำ) เสร็จ 2026-10-01
> ยังเหลือใน M2: sprite จริงของคุณนายวรรณ — แต่ดูข้อ 10 ก่อน (ข้อเสนอเปลี่ยนทิศ)
- **M0 (เสร็จ)**: โครง, ภาพ, ตัวละคร, 3 ห้อง, บทที่ 1 แบบ linear
- **M1 — บอร์ดงาน + เวลา** (ระบบ 1–2) **[เสร็จ 2026-10-01]**: jobs.json (6 งาน), UI บอร์ดงาน, ช่องเก็บของ 2, นาฬิกา 6 ช่วง + นอน,
  ส่งสายได้เงินน้อยลง, แสงเปลี่ยนตามเวลา. ยังขาดในเกณฑ์ M1: งานแบบปริศนา (ข้อ 4 ของเจ้าของ) และของ BKK ในฉาก (ข้อ 5) → ทำใน M2
- **M2 — ย่านตอบสนอง** (ระบบ 3 + ท่าเรือ + คุณนายวรรณ): ชื่อเสียง, งานบริษัท vs ชาวบ้าน, ด่านตรวจ
- **M3 — รถและการต่อสู้** (ระบบ 4–5): อัปเกรด, ศัตรู 3 แบบ, หลบ
- **M4 — vertical slice ครบ** + เมนู/เซฟ/เสียง → ให้คนอื่นลองเล่น
- หลังจากนั้นค่อยทำบทที่ 2–3 เต็ม

## 9. คำตอบจากเจ้าของ (2026-10-01) **[ตัดสินใจแล้ว]**
1. **สั้น** — ทำเวอร์ชันสั้นจบได้ (เป้า 2–3 ชม., ~5–7 วันในเกม) ลองก่อน ค่อยขยาย
2. **ตลก** — โทนละครซอย ตัวละครปากจัด สถานการณ์เพี้ยนๆ บริษัทไอน้ำเป็นตัวร้ายแบบน่าหมั่นไส้ ไม่โหด
3. **การเลือกกลางๆ** — เปลี่ยนบทพูด ราคา งานที่เปิด และฉากจบ; ไม่ถึงขั้นร้านปิดถาวร/ตัวละครหาย
4. **เน้นปริศนา** — ต่อสู้เป็นส่วนน้อย: หุ่นรวน = อุปสรรคที่ "แก้" ได้ (ปิดวาล์ว ล่อด้วยของ หาทางอ้อม) มากกว่าตีจนตาย;
   งานส่งของควรมีปมให้คิด (ของแตกง่าย ต้องส่งก่อนร้อน / ต้องหาคนรับที่ย้ายที่ / ของผิดกล่อง)
5. **ฉากต้อง "เก๊ต" ว่าเป็นกรุงเทพฯ** — ทุกห้องต้องมีของที่มีแค่ที่นี่: วินมอเตอร์ไซค์+เสื้อกั๊ก, สายไฟพันเสา, รถเข็นก๋วยเตี๋ยว,
   ศาลพระภูมิ, แผงลอยริมทาง, ป้ายรถเมล์, ตู้โทรศัพท์, คลอง+เรือหางยาว, แมวร้านชำ, ป้ายรถตุ๊กตุ๊ก, ฝาท่อ กทม.
   → เพิ่มเป็นเกณฑ์ตรวจทุกห้อง: "ถ้าลบป้ายชื่อห้องออก ยังรู้ไหมว่านี่กรุงเทพฯ"

## 10. ร่าง 2 — "ไรเดอร์ห้าดาว" : rider vs platform vs ลูกค้า (เจ้าของ 2026-10-01) **[ตัดสินใจแล้ว — กทม. ปัจจุบัน]**
> **P0 เสร็จ 2026-10-01** (ดู 10.8). ข้อ 1–9 ด้านบน = แผนเวอร์ชันย่านตายตัว (เก็บไว้เป็นประวัติ)
> ร่าง 2 แทนข้อ 1–8: ยุบ "ย่าน" ตายตัว + บอร์ดงาน + เนื้อเรื่อง 3 บท → เมืองสุ่ม + แอปไรเดอร์ + เอาตัวรอดรายวัน
> เจ้าของ: "ยุบย่าน ทำ random gen", "ใช้ app แทน board", "map ของ BKK", "งานซ้อน", "evil corp → platform",
> "อาหาร vs เอกสาร/พัสดุ behavior ต่างกัน", "goal วิ่งงาน เก็บเงิน ค่าเช่ารถ ค่าใช้จ่าย ค่าน้ำมัน", "ทั้ง serious ทั้ง absurd",
> "มีสิทธิ viral เพราะ rider/ลูกค้าจริงเข้าใจปัญหา", ปัญหาตั้งต้น: หนี้นอกระบบ (หนีเจ้าหนี้), platform โหด, ปักหมุดไม่ตรง, รีวิว 1 ดาว

### 10.1 ประโยคเดียว
ไรเดอร์ติดหนี้ดอกลอย วิ่งงานในกรุงเทพฯ ที่สุ่มใหม่ทุกเกม ผ่านแอปที่ลดค่ารอบเมื่อไหร่ก็ได้ ส่งให้ลูกค้าที่ปักหมุดผิดแล้วให้หนึ่งดาว
— ต้องอยู่รอดให้ครบ N วันโดยบัญชีไม่โดนปิด รถไม่โดนยึด และหนีเจ้าหนี้ให้พ้น

### 10.2 Loop รายวัน
```
เช้า   : จ่ายค่าเช่ารถ/ผ่อนรถ + ดอกรายวัน (ไม่จ่าย = เจ้าหนี้ตามหา) → เปิดแอป "ออนไลน์" → ประกาศนโยบายประจำวัน
วิ่งงาน: ออเดอร์เด้ง (นับถอยหลังกดรับ, ปฏิเสธบ่อย = อัตรารับงานตก) → แผนที่: เลือกเส้นทางไปจุดรับ (เวลา+น้ำมัน+เสี่ยง)
         → ลงที่สถานที่ (ฉาก iso สุ่มตามประเภท) → ปัญหาเฉพาะที่ → รับของ → วิ่งไปส่ง → ปัญหาปลายทาง → ดาว + ทิป
ค่ำ    : สรุปรายรับ-รายจ่ายจริงจัง (แบบสลิป) → นอน (หรือวิ่งต่อแลกความล้า)
```
เป้า (เกมสั้น 5–7 วัน): ปลดเงินต้นหนี้นอกระบบ หรืออย่างน้อยรอด — แพ้เมื่อ บัญชีโดนปิด (เรตติ้งต่ำ) / รถโดนยึด / หมดตัว

### 10.3 เมืองสุ่ม (random gen) — สถานที่ = ประเภท × ตัวแปร
ทุกเกมสุ่มแผนที่ (กราฟจุด ~12–20 จุด ชื่อซอยสุ่มสไตล์ "สุขุมวิท 101/1 แยก 3") แต่ละจุดเป็นประเภทหนึ่ง แล้วสร้างฉากจาก template ของประเภทนั้น + prop สุ่ม
| ประเภท | ปัญหา/ปริศนาประจำที่ |
|---|---|
| ตลาด (หลายร้าน อาหาร+ของ) | หาร้านให้เจอในแผงที่หน้าตาเหมือนกัน, คนแน่น, ที่จอดไม่มี |
| ร้านอาหาร | คิวรอนาน (รอ vs ยกเลิก), ร้านทำผิดเมนู, ร้านปิดแต่แอปบอกเปิด |
| บ้าน/หมู่บ้าน | หมาไล่ (stealth แบบหุ่นเดิม), บ้านเลขที่ไม่เรียง, ปักหมุดกลางหมู่บ้าน |
| คอนโด | รปภ. ไม่ให้ขึ้น, ต้องใช้ลิฟต์ขนของ/ถอดแจ็กเก็ต, ลูกค้าไม่ยอมลงมา |
| ออฟฟิศ | เอกสารต้องเซ็นโดย "คนที่ถูกต้อง", รีเซปชันส่งต่อชั้น, เส้นตายธนาคารปิด |
| ปั๊มน้ำมัน | เติมน้ำมัน, ห้องน้ำ, จุดพักไรเดอร์ = ข่าวลือ/เตือนภัย |
| อู่ | ซ่อมรถ/ยางแบน, ผ่อนรถ, อัปเกรดกล่อง |
| ฯลฯ | วินฯ, เซเว่น, โรงพยาบาล, วัด, ป้ายรถเมล์, ใต้ทางด่วน |

### 10.4 งานแต่ละแบบ = behavior ต่างกัน
- **อาหาร**: ความร้อนลดตามเวลา (ร้อน→อุ่น→เย็นชืด) มีผลกับดาว, ขี่เร็ว/ทางขรุขระ = หก, น้ำแข็งละลาย, รอร้าน
- **เอกสาร**: ต้องถึงมือคนชื่อนั้น (ตรวจบัตร/ลายเซ็น), เส้นตายแข็ง, ส่งผิดคน = ส่งไม่สำเร็จ
- **พัสดุ**: ขนาดกินช่อง, COD เก็บเงินปลายทาง (ลูกค้าไม่รับ = ไรเดอร์แบกค่าของ), ผู้รับไม่อยู่ = ฝาก รปภ. (เสี่ยงโดนร้องเรียน)
- **งานเพี้ยน** (absurd): ต่อคิวแทน, ส่งแมว, ส่งโอ่ง, ซื้อหวยให้, ไปรับกุญแจที่ลืมไว้
- **งานซ้อน**: รับได้ 2–3 พร้อมกัน แอปชอบยัดงานซ้อนทางตรงข้ามกัน

### 10.5 ปัญหาจริง → กลไก (ค้นมา 2026-10-01)
- ค่ารอบโดนลดโดยแจ้งล่วงหน้าวันเดียว ไม่มีคำอธิบาย (ค่ารอบเริ่มต้นเคยราว 60 บาท ปี 2018 เหลือ 38–40 บาท) → **ประกาศนโยบายรายวัน** เปลี่ยนค่ารอบ/โบนัส
- รายได้ตก (จากราว 2,000 เหลือ 900 บาท/วันในบางวัน), วิ่งหลายแอปสลับกัน → เป้ารายได้รายวันที่ตึงจริง
- ชั่วโมงยาว (ราว 45% ทำเกิน 60 ชม./สัปดาห์), อุบัติเหตุราว 1 ใน 3 เพราะเร่งเวลา/ดูมือถือ → **ความล้า** + เลือก "ขี่เร็ว vs ขี่ปลอดภัย"
- ประกันแค่บางเงื่อนไข จ่ายค่ารักษาเอง → อุบัติเหตุ = ค่าใช้จ่ายก้อน
- อัลกอริทึมจ่ายงานไม่เป็นธรรม/รวน, พ่วงงาน 2–3 งาน → งานซ้อนแปลกๆ, โบนัส "ครบ 20 งาน" ที่งานที่ 20 ไม่ยอมเด้ง
- ลูกค้ายกเลิกหลังซื้อของแล้ว / COD ไม่รับ → ไรเดอร์จ่ายค่าอาหารเอง (เลือกกินเองได้ = absurd)
- ปักหมุดผิด (หมุดกลางหมู่บ้าน) + ลูกค้าไม่รับสาย → ปริศนาหาบ้าน: ถามคนแถวนั้น, ดูเบาะแสในแชท
- ห้าง/คอนโดห้ามใช้ลิฟต์ปกติ ให้ถอดแจ็กเก็ต, ลูกค้าต้องลงมารับ → ฉากคอนโด
- เรตติ้งเอนเข้าข้างลูกค้า, ร้องเรียนไม่มีผล, ปิดบัญชีไม่บอกเหตุผล → **รีวิว 1 ดาว** ที่ไม่ใช่ความผิดเรา + มินิเกมอุทธรณ์กับแชทบอท
- ค่าใช้จ่ายบังคับ (กล่อง/เสื้อ/ค่าสมัคร), น้ำมัน, ค่าเช่ารถ/ผ่อน, แอปปล่อยกู้แล้วหักจากรายได้ → สลิปรายจ่ายรายวัน
- หนี้นอกระบบ "ดอกลอย" (จ่ายแต่ดอก เงินต้นไม่ลด) → ดอกรายวัน + **เจ้าหนี้ตามหา**: โผล่ตามสถานที่ มีกรวยสายตา (ใช้ระบบ PatrolBot เดิม) ต้องหลบ/หนี
- ตำรวจ/เทศกิจ จอดผิดที่, ฝนตก (ค่ารอบพิเศษแต่ลื่น อาหารเปียก), น้ำท่วมเส้นทาง → อีเวนต์บนแผนที่

### 10.6 ตัวเลขที่ต้องติดตาม (แทนชื่อเสียง 3 ฝ่าย)

## 11. แผนหลัก (ร่าง 4) — "ไรเดอร์ห้าดาว: กรุงเทพฯ 2090" เกมผจญภัยตลกมีตอนจบ **[เจ้าของเห็นด้วย 2026-10-02]**

### 11.0 ทำไมเปลี่ยน (คำเจ้าของ)
- P2 "ไม่สนุก เหมือนเราทำ app rider", "การจำลองปัญหา rider มันไม่สนุก" → **เลิกจำลองอาชีพ** (แอป ค่ารอบ น้ำมัน ความล้า เรตติ้ง นโยบาย นาฬิกาเร่ง)
- ที่สนุกจริง: "สำรวจห้อง แล้วบทสนทนา/ของมันฮาๆ", "ตอน steampunk สนุกกว่า"
- อยากได้: "มีตอนจบ", "plot ย่อย และ plot ใหญ่ที่ไม่โง่", "เป็นหนี้นอกระบบ แล้วมีคนทวง หรือหุ่นทวง",
  "กทม. อนาคต น่าจะจมน้ำ", "puzzle, inventory, ผสมของ — Monkey Island แต่ simple"

### 11.1 ประโยคเดียว
ไรเดอร์ติดหนี้นอกระบบในกรุงเทพฯ ปี 2090 ที่จมไปครึ่งเมือง หนีคนทวงกับหุ่นทวงไปพร้อมกับส่งกล่องปริศนาถึง "บ้านเลขที่ 0"
แล้วค้นพบว่าหนี้ของตัวเองกับน้ำที่ท่วมซอยทุกปีเป็นเรื่องเดียวกัน

### 11.2 โลก
- น้ำท่วมจนไฟฟ้าแพง/ปันส่วน → ซอยเก่ากลับไปใช้ไอน้ำ ดีเซล ทองเหลือง (**หน้าตา steampunk มีเหตุผลในเรื่อง**)
- ซอยเป็นคลอง บ้านยกเสา คอนโดเข้าทางชั้น 3, คนรวยอยู่หลัง "กำแพงกันทะเล" ของ **บริษัท ป้องกันภัย จำกัด** (คุมกำแพง + เครื่องสูบน้ำ)
- ไรเดอร์ขี่มอเตอร์ไซค์ลอยน้ำ / เรือหางยาวไอน้ำ

### 11.3 Plot ใหญ่ (ปูเบาะแสไว้ใน plot ย่อยตั้งแต่บท 1 — ย้อนดูแล้วต้อง "อ๋อ")
- **เปิด**: ตัวเอกกู้นอกระบบดอกลอยมาซื้อเรือเตอร์ไซค์ คนทวงตามถึงซอย; งานแรก = ส่งกล่องทองเหลืองไป "บ้านเลขที่ 0" ที่ไม่มีในแผนที่
- **บท 1**: ตามหาจนเจอว่าบ้านเลขที่ 0 = สถานีสูบน้ำเก่าใต้ซอยที่ถูกปิดตาย
- **บท 2**: เบาะแสจากเรื่องย่อย: บริษัทกำหนดให้ซอยเป็น **แก้มลิงลับ** รับน้ำล้นแทนย่านตึกสูง (น้ำในซอยสูงขึ้นทุกปีทั้งที่ทะเลไม่ได้สูงขนาดนั้น)
- **หักมุม**: แก๊งเงินกู้ที่ทวงทั้งซอยเป็นของบริษัท — หนี้คือเครื่องมือบีบให้คนขายที่ถูกๆ ให้เป็นแก้มลิงถาวร, **หนี้ของตัวเอกถูกบริษัทซื้อไปตั้งแต่วันแรก**;
  คนส่งกล่อง = **คุณนายวรรณ** วิศวกรเครื่องสูบน้ำของบริษัท (ในกล่อง = กุญแจสถานี + แผนผังหลักฐาน)
- **บท 3 / ตอนจบ**: ขายกล่องให้บริษัท (หนี้หมด ซอยจม) / เปิดสถานีกับคนในซอย / แฉหลักฐาน — ผลขึ้นกับว่าช่วยเรื่องย่อยของใครไว้ → ตอนจบหลายแบบ
- กติกา "ไม่โง่": ทุกคนมีสิ่งที่อยากได้จริง ไม่มีตัวร้ายที่ร้ายเพราะอยากร้าย, เบาะแสยุติธรรม, มุกมาจากนิสัยตัวละคร ไม่ใช่มุกสุ่ม

### 11.4 Plot ย่อย (มีตอนจบของมันเอง + ช่วยในบท 3)
- **ลุงโต๊ะสาม × ป้านก** (ก๋วยเตี๋ยวเรือ บนเรือจริง): รัก 40 ปีผ่านน้ำจิ้มไก่ → งานเลี้ยงของสองคน = จุดอพยพ
- **ป้าจุ๋ม**: เครือข่ายเผือก + ลอตเตอรี่ 69 → แจ้งข่าวทั้งซอยในสิบนาที
- **ช่างแดง**: นอนใต้เรือหลบหุ่นทวงหนี้ = อดีตวิศวกรสถานี → รู้ทางเข้า
- **น้องเก่ง**: "โปรเพลเยอร์" ตาไวกับเข็มวัดแรงดัน → คุมวาล์ว
- **หุ่นทวงหนี้เบอร์ 9**: ล่าตัวเอก พลาดตลอด เริ่มลอกนิสัยคน → เลือกข้าง
- **แมวส้มโอ**: ขโมยของไปซ่อน → กองสมบัติมีเบาะแส
- **เจ้าหนี้ตัวจริง (เจ๊/เฮีย)**: มีเหตุผลของตัวเอง ถูกบริษัทใช้งานเหมือนกัน

### 11.5 วิธีเล่น — Monkey Island แต่ simple
- **แตะอย่างเดียว ไม่มีแผงคำกริยา**: แตะพื้น = เดิน, แตะคน = คุย, แตะของ = ดู/หยิบ (ของที่หยิบได้เข้ากระเป๋าเอง)
- **กระเป๋า (inventory)**: แถบล่างจอ ของมีไอคอน + ชื่อ + คำบรรยายฮาๆ หนึ่งบรรทัด, ไม่เกิน ~8 ชิ้นพร้อมกัน
- **ใช้ของ**: แตะของในกระเป๋า (ของติดนิ้ว) → แตะคน/ของในฉาก = "ใช้ X กับ Y"
- **ผสมของ**: แตะของ A → แตะของ B ในกระเป๋า = ได้ของใหม่ (สูตรเป็นข้อมูล)
- **ผิดก็ฮา**: ใช้/ผสมผิด → ตัวเอกพูดตอบตามของ/เป้าหมาย (มีชุดคำตอบสำรองไม่ให้ซ้ำ) — ไม่มีลงโทษ ไม่ตาย ไม่ติดตาย
- **ปริศนายุติธรรม**: ไม่ต้องคลำพิกเซล (กดค้าง = จุดที่แตะได้เรืองแสง), ทุกปริศนามีเบาะแสในบทพูด, มีคนให้ใบ้ (โทรหาป้าจุ๋ม)
- **น้ำขึ้น-น้ำลง** = กลไกปริศนา: บางห้อง/ทางเข้าได้ตอนน้ำลง บางของลอยมาตอนน้ำขึ้น (เปลี่ยนด้วยการรอ/นอน/เหตุการณ์)
- **ย่องหลบ** คนทวง/หุ่นทวง (PatrolBot กรวยสายตาเดิม) เป็นปริศนาบางห้อง ไม่ใช่ทุกห้อง
- **เดินทาง**: ขับเรือ/เรือเตอร์ไซค์ตามคลอง (ใช้ระบบเลนของช่วงขี่) — สั้น และข้ามได้
- **เวลา**: แบ่งเป็นวันตามเนื้อเรื่อง ไม่มีนาฬิกาเร่ง; หนี้เป็นแรงผลักดันของเรื่อง ไม่ใช่มาตรวัด

### 11.6 ข้อมูลปริศนา (แนวทาง implementation)

### 12.3 คนทวง/หุ่นทวง = "ประตูที่มีชีวิต" (แทนย่องเรียลไทม์)
- ตัดกรวยสายตา การไล่ และการย่องไปด้านหลังออกจากทุกห้อง — ทุกอย่างในเกมเป็น "คิดแล้วแตะ"
- ยืนขวางจุดสำคัญ เดินเข้าใกล้ = จับทันทีแบบคาดเดาได้ + บทพูดฮาที่**ใบ้จุดอ่อน** + ผลักกลับ (ไม่มีลงโทษ ไม่ตาย)
- ผ่านได้ด้วยปริศนาเท่านั้น: พี่หนวดชอบลูกทุ่ง (วิทยุ), เบอร์ 9 หันตามเสียงเสมอ (ทำเสียงฝั่งตรงข้าม → แตะหลังดึงฟิวส์), หุ่นบริษัทฟังเก้า, ป้อมยามบท 3 ใช้กฎชุดเดียวกัน
- โดนจับตอนถือของ = ของชิ้นนั้นถูก "ยึดหนี้" ไปอยู่แพเจ๊เกียว ต้องไปเอาคืน (ปริศนาย่อยสั้นๆ) — ผลแบบเรื่อง ไม่ใช่แบบเกม
- เส้นเรื่องของพี่หนวด/เก้าคงเดิม (ขวาง → ตกงาน/ได้ชื่อ → เป็นพวก)

### 12.4 ของหลอก (red herring) — กติกา
- ส่วนใหญ่ = prop แตะดูได้ มีเรื่องเล่า ไม่หยิบ (กระเป๋า 8 ช่อง)
- หยิบได้ไม่เกิน 3–4 ชิ้นทั้งเกม เฉพาะที่มุกดีจริง และต้องมีคำตอบฮาตอนใช้ผิดทุกที่ (`fail` ใน puzzles.json) เช่น พระเครื่องกันน้ำ (ใบรับประกัน "ไม่ครอบคลุมน้ำท่วม"), ใบเสร็จค่าปรับจอดเรือในที่ห้ามจอด

| **ลุงปลาทู / เจ๊หมวย / หุ่นขายลอตเตอรี่** | ตลาดน้ำดาดฟ้า `roof_market` | ลุงปลาทู: แมวขโมยปลาทุกวัน; เจ๊หมวย: ของแห้งที่ไม่เคยแห้ง; หุ่นลอตเตอรี่ = ของบริษัท (ที่ขายใบ "รางวัล" ให้ป้าจุ๋ม) | ตลาดไม่รับเงิน (ไรเดอร์ไม่มี) = **แลกของเป็นทอด** แบบ MI; ของหลอกส่วนใหญ่อยู่ที่นี่ | ตลาด "น้ำ" ที่อยู่สูงสุดในซอย; ป้าย "ห้ามจอดเรือบนดาดฟ้า" |
| **น้องบอย** (เจ้าหน้าที่เขต ฝ่ายป้าย) | โผล่คนละห้องตามบท | KPI = จำนวนป้ายที่ติดได้; ไม่เคยมีงบอื่นนอกจากงบป้าย | ป้ายเปล่า = กระดาษ (ลอกลายขีดน้ำ), ป้ายโครงการ = ไม้กระดาน; บท 3 ป้าย "ห้ามอพยพโดยไม่ได้รับอนุญาต" | ป้ายทุกใบ "ระยะที่ N" เพิ่มทีละ 1 ทุกครั้งที่เจอ; ถาม "น้ำท่วมแล้วทำยังไง" ตอบ "ติดป้ายเพิ่ม" |
| **พี่เบิ้ม จอมบุญ** (อินฟลูเอนเซอร์สายช่วยเหลือ "มูลนิธิจอมบุญลอยน้ำ" — เจ้าของขอ 2026-10-02: "สร้างภาพ ช่วยเหลือคน แต่รับบริจาค เทาๆ") | เรือไลฟ์สดติดจอ LED ลอยไปทุกห้องตามบท (ฐานที่ท่าเรือ) | ยอดวิว + ยอดโอน; **ช่วยคนจริง** แต่ช่วยเฉพาะที่มีกล้อง; กองเรือ 6 ลำซื้อด้วยเงินบริจาค "ของมูลนิธิ"; เทาตรงที่เขาเองก็ไม่รู้ว่าตัวเองช่วยเพราะอะไร | บท 1 ของหลอก/มุก (ไลฟ์ช่วยไรเดอร์ที่ไม่ได้ขอ), บท 2 **โดรนของเขาถ่ายท่อบริษัทเปิดตีสามไว้โดยบังเอิญ** (ถ่ายเพื่อยอดวิว ไม่เคยดู) = หลักฐานทางเลือก, บท 3 กองเรือ = "พา" ได้ แต่ต้องมีกล้อง (ไลฟ์การอพยพ) และบริษัทเสนอสปอนเซอร์ให้เขาเงียบ | ทุกประโยคมี "โอนมาที่เบอร์นี้"; ถามว่าช่วยไหม ตอบ "ขอตั้งกล้องก่อน"; ป้ายเรือ "ช่วยได้ทุกเรื่อง (ยกเว้นเรื่องเงิน)" |
| **คุณหญิงลออ** + พุดเดิ้ลบนห่วงยาง | คอนโดชั้น 3 `condo` (บท 2–3, เผื่อ) | ย้ายไม่ทันตอนน้ำขึ้น คอนโดเป็น "สินทรัพย์" ขายไม่ออก | ของหลอกชั้นดี + ตัวแทน "คนรวยที่โดนเหมือนกัน" (ชื่ออยู่ในรายชื่อลูกหนี้ด้วย) | สั่งของจากแอปทุกวันทั้งที่ลิฟต์จมน้ำ; ไรเดอร์คือคนเดียวที่มาถึง |

### 12.6 บท 1 "บ้านเลขที่ 0" — ยืดจาก 10 ขั้น เป็น ~25 ขั้น
เป้าของบทเหมือนเดิม (ส่งกล่องให้ถึงบ้านเลขที่ 0) แต่ **ป้าจุ๋มกลายเป็น hub** และสถานีต้องรวม 3 สาย
- **สาย A กุญแจกับเรือ (สอนเล่น, ยืด +2)**: ไม้แขวน+หมากฝรั่ง → ร่อง → กุญแจ (เดิม). วิทยุ: ใส่ถ่านแล้ว**มีแต่เสียงซ่า** → ต้องรู้คลื่น
  (ป้ายท่าเรือ "ส.ว.ท. 2090 สถานีเดียวที่เหลือ" / พี่เปิ้ลบอก) → แตะวิทยุอีกทีจูน → ลูกทุ่ง → พี่หนวดเต้น → เสียบกุญแจ. พี่หนวดเป็นประตูมีชีวิตตัวแรก:
  เดินเข้าใกล้ = จับ + ใบ้ ("เพลงนี้ ... เมียพี่") + ผลักกลับ; ถือของอยู่ = ของถูกยึดไปแพเจ๊เกียว → `know_kiao` ตั้งแต่บท 1 (ไปเอาคืน)
- **สาย B กล่องของป้านก (ยืด +2)**: ป้านกหูไม่ดี → เขียนสมุด (เดิม) แต่ป้านกให้กล่องเฉพาะ**คนที่สั่งเมนูเดียวกับคนฝาก** — จดหมายมีคราบน้ำซุป
  + ป.ล. "สั่งอย่างที่ฉันเคยสั่ง"; เมนูบนเรือมี 6 อย่าง เดาจากคราบ (น้ำตก) + ลุงโต๊ะสามเล่าว่า "ผู้หญิงใส่สูทสั่งเส้นเล็ก ไม่ใส่ถั่วงอก"
  → เขียน "เส้นเล็กน้ำตกไม่ใส่ถั่วงอก" ลงสมุด → กล่อง. (คำที่ผิด = ป้านกตักเมนูผิดมาให้จริงๆ ทีละชาม)
- **สาย C ป้าจุ๋มขอข่าว 3 เรื่อง** (เดิมจดหมาย 1 ฉบับจบ): ข่าวที่ป้ายังไม่รู้ = (1) จดหมายไม่ลงชื่อ (เดิม), (2) **ความลับลุงโต๊ะสาม**: ป้านกคืนซองน้ำจิ้มเปล่า
  1 ซองหลังรับ 40 ซอง — ด้านหลังซองมีลายมือ "โต๊ะ 3" → ป้าจุ๋ม, (3) **ใครขโมยที่ม้วนผมป้า** (ป้าโทษเพื่อนบ้านไปแล้วทั้งซอย): ตามแมวส้มโอ →
  ตลาดดาดฟ้า (พี่เปิ้ลบอกทาง) → ลุงปลาทูให้ปลาถ้าช่วยจับแมว → รอน้ำขึ้น → หลังคาแมว → วางปลา → แมวมา → กองสมบัติ = ที่ม้วนผม (+ ของหลอก 2 ชิ้น)
  → ครบ 3 ข่าว ป้าจุ๋มบอกที่อยู่บ้านเลขที่ 0 + ช่างแดง (`know_garage`, `know_gate`, `jum_friend`)
- **สาย D ทางเข้าสถานี (ยืด +3)**: อู่ช่างแดง: เบอร์ 9 ยืนขวางเรือคว่ำ "หันตามเสียงเสมอ" (บทพูดตอนโดนจับใบ้) → ต้องมีเสียงฝั่งตรงข้าม:
  วัดหอระฆัง → หลวงพี่ให้**ประทัดงานวัด**ถ้าช่วยตีระฆังตอนน้ำขึ้น (ระฆังหนัก ต้องใช้มือหมุน? ไม่ — ใช้ไม้แขวนเสื้อเกี่ยวเชือกที่ขาด) →
  จุดประทัดฝั่งซ้ายอู่ → เบอร์ 9 หันไป → แตะหลังดึงฟิวส์ (ไม่มีจังหวะ) → ช่างแดงออกมา → มือหมุนหัก + เทป → มือหมุน (เดิม)
- **ด่านใหญ่**: ประตูน้ำต้องน้ำลง + มือหมุน + (ใหม่) หุ่นบริษัทรุ่นเก่าเฝ้าประตูน้ำตั้งแต่บท 1 ตอนน้ำลง → ลุงหมอน้ำสอนกฎ: ไปศาลาเจอป้าย "วันนี้น้ำขึ้นตลอดวัน
  (ยืนยันแล้ว)" → น้ำลง; หุ่นบริษัทเชื่อลุง: ถ้าป้ายบอก "น้ำขึ้น" หุ่นจะกลับฐานเพราะ "ไม่มีอะไรให้เฝ้าตอนน้ำขึ้น" → ผู้เล่นต้องให้ลุงพยากรณ์
  "น้ำขึ้น" (ลุงพยากรณ์ตามปลาทอง → ปลาทองหายไป (แมว) → เอาคืนจากกองสมบัติ) → เข้าสถานี → `chapter1_done`
- บท 1 ใช้ห้อง: 8 เดิม + hall, roof_market, temple, boat_rank, cat_roof (= 13); kiao_raft เปิดเฉพาะเมื่อโดนยึดของ

### 12.7 บท 2 "ใครซื้อหนี้" — ยืดจาก 8 ขั้น เป็น ~22 ขั้น + หลักฐาน 3 ชิ้น
- **สาย E ชิปความจำ (ยืด +2)**: เจ๊เกียว → ตั้งชื่อเก้า (เดิม) → ชิป → น้องเก่งแฮ็กไม่ได้ "หัวต่อคนละรุ่น" → สายแปลงของลูกชายพี่เปิ้ล
  (พี่เปิ้ลให้ถ้าไรเดอร์เอาจดหมายจากลูกชายมา → ลูกชาย = พนักงานในป้อมยาม ส่งข้อความผ่านคุณบีม "ตามระเบียบ") → รายชื่อลูกหนี้ (เดิม)
  รายชื่อมีชื่อคุณบีม + คุณหญิงลออ ด้วย (ปูบท 3)
- **สาย F ลอตเตอรี่ป้าจุ๋ม (ยืด +3)**: ป้าจุ๋มจะเซ็น "ใบรับรางวัล" (เดิม) แต่ตอนนี้ไม่เชื่อรายชื่ออย่างเดียว ("กระดาษใครก็พิมพ์ได้") → ป้าเชื่อ 2 คนในโลก:
  ลุงหมอน้ำ กับหุ่นขายลอตเตอรี่ → ให้ลุงหมอน้ำทาย "เลข 69 ถูกรางวัลแน่นอน" (= ไม่ถูก) ต่อหน้าป้า: ต้องพาป้าไปศาลา (ป้าไม่ไปไหนถ้าไม่มีข่าว) หรือเอาวิทยุ
  ไปให้ลุงพยากรณ์ออกอากาศ (สถานีเดียวที่เหลือ) → ป้าฉีกใบ → แว่น (เดิม)
- **สาย G จดหมายรัก (เดิม)**: ลุง → จดหมาย → ป้านกต้องมีแว่น → อ่าน (ป.ล. ตีสาม)
- **สาย H ขีดระดับน้ำที่หอระฆัง (ใหม่)**: หลวงพี่จดระดับน้ำทุกคืนตีสามมา 30 ปีบนเสาหอระฆัง — ต้อง**ลอกลาย** (กระดาษ + ถ่าน): กระดาษ = ป้ายเปล่าของน้องบอย
  (แลกกับช่วยติดป้าย "ระยะที่ 15"), ถ่าน = ถ่านไม้จากเตาป้านก (ป้านกให้ถ้าร้านไม่ยุ่ง = ตอนลุงโต๊ะสามสั่งก๋วยเตี๋ยวจริงๆ ครั้งแรกใน 40 ปี) → ลอกลาย → เห็นว่าน้ำขึ้น
  "ทีละสองเซน ทุกคืน ตั้งแต่วันที่สถานีปิด"
- **สาย I คุณบีม (ใหม่, ของหลอกครึ่งปริศนาครึ่ง)**: ป้อมยามเปิดบท 2; คุณบีมขาย "ประกันน้ำท่วม" ให้ไรเดอร์ แลกกับกรอกแบบสอบถาม 5 ดาว → ได้โบรชัวร์
  "โครงการพื้นที่รับน้ำชุมชน" ที่มีแผนที่ซอยส่งไวระบายสีน้ำเงิน = หลักฐานโดยไม่รู้ตัว (คุณบีม: "ภาพประกอบครับ ไม่ใช่แผนที่")
- **ด่านใหญ่**: คุณนายวรรณโผล่เมื่อมี**หลักฐาน 3 ชิ้น** (รายชื่อ + จดหมายรัก/ขีดระดับน้ำ + โบรชัวร์) → เฉลย (เดิม) → `chapter2_done`
  (ขีดระดับน้ำกับจดหมายรักเป็นหลักฐานชนิดเดียวกัน — ผู้เล่นต้องได้อย่างน้อย 1 ใน 2 → เส้นทางไม่บังคับลำดับ)

### 12.8 บท 3 "คืนตีสาม" — **ตอนจบเดียว, linear, จบดีที่สุด** (เจ้าของตอบ 2026-10-02: "ทำ linear แต่จบดีที่สุดไปเลยก็ได้นะ") **[ตัดสินใจแล้ว]**
สรุปที่ใช้จริง (ข้อเสนอ 3 แกนด้านล่างเก็บไว้เป็นประวัติ ใช้เฉพาะแกน 3):
- **ตอนจบเดียว = ซอยรอด ไรเดอร์ห้าดาวจากซอย** ไม่มีตอนจบขาย/จม/เปียก (ตัด `sold/sunk/wet` ออก; ข้อเสนอขายกล่องของบริษัทยังมีเป็นฉาก แต่ไรเดอร์ปฏิเสธเองเป็นมุก ไม่ใช่ทางเลือก)
- **บท 3 เป็นสายปริศนาบังคับ**: ต้องได้ครบ ปลุก (ป้าจุ๋ม+โทรโข่ง **และ** ระฆังหลวงพี่) · พา (วินพี่เปิ้ล + กองเรือพี่เบิ้ม + พี่หนวดพาย) · ที่ไป (งานแต่งบนเรือป้านก + คุณบีมเปิดกำแพง)
  · เวลา (ลุงหมอน้ำประกาศผิด) → เปิดวาล์ว → ขบวนเรือตีสาม → ตอนจบ. การชนในขบวนเรือ = คนเปียก (การ์ดส่งท้ายเปลี่ยน) ไม่ตัดตอนจบ
- **การ์ดส่งท้ายรายคน (เจ้าของ: ok)** = ส่วนเดียวที่ต่างกันต่อการเล่น ตาม plot ย่อยที่ทำ/ไม่ทำ (ลุง×ป้านก, เก้า, คุณบีม, ป้าจุ๋ม, พี่เบิ้ม, ลุงหมอน้ำ, ช่างแดง, เจ๊เกียว, น้องเก่ง, แมวส้มโอ ...)
  plot ย่อยที่ไม่บังคับยังมีคุณค่าตรงนี้ (เล่นซ้ำเพื่อเก็บการ์ดครบ)

(ประวัติ — ข้อเสนอเดิมก่อนเจ้าของตอบ)
ตอนจบประกอบจาก 3 แกนที่แยกกัน ผู้เล่นเห็นผลของ "สิ่งที่ทำ" ไม่ใช่คะแนน
- **แกน 1 การตัดสินใจเรื่องกล่อง (เลือกเอง 3 ทาง)**: **ขาย** ให้บริษัทผ่านเจ๊เกียว/คุณบีม (หนี้หาย ซอยจมต่อ) / **เปิดวาล์ว** (กลับทิศน้ำ ซอยจมหนึ่งคืน ต้องอพยพ)
  / **แฉ** (ใหม่ — DESIGN 11.3 เคยวางไว้แต่ยังไม่ได้ทำ): เอาหลักฐานออกอากาศทางวิทยุสถานีเดียวที่เหลือ (ลุงหมอน้ำ) หรือไลฟ์ของพี่เบิ้ม → บริษัทไม่กล้าเปิดท่อคืนนั้น
  ซอยไม่จม แต่ไม่มีใครกลับทิศน้ำ = ชนะแบบไม่เสียอะไรและไม่ได้อะไร (น้ำยังสูงเท่าเดิมตลอดไป) — ตอนจบ "แห้งแต่ไม่สะอาด"
- **แกน 2 การอพยพ (เฉพาะทางเปิดวาล์ว) ต้องมี 3 อย่าง แต่ละอย่างมีอย่างน้อย 2 ทาง**:
  | ต้องมี | ทาง ก | ทาง ข | ถ้าขาด (ตอนจบเปลี่ยนหน้าตา ไม่ใช่เกรด) |
  |---|---|---|---|
  | **ปลุก** | ป้าจุ๋ม + โทรโข่งพี่หนวด | ระฆังหลวงพี่ (เชือกซ่อมแล้ว) | ครึ่งซอยหลับ ตื่นมาบนหลังคา |
  | **พา** | เรือวินพี่เปิ้ล | กองเรือพี่เบิ้ม (ต้องยอมให้ไลฟ์) + พี่หนวดพาย | คนเดินลุยน้ำ เปียกแต่รอด |
  | **ที่ไป** | งานแต่งบนเรือป้านก (ลุง×ป้านก) | คุณบีมเปิดประตูกำแพงให้หนึ่งคืน | ลอยคออยู่ในเรือจนเช้า |
  + **เวลา** (โบนัส): ลุงหมอน้ำประกาศผิดเวลา → บริษัทเปิดท่อช้า → ชดเชยสิ่งที่ขาดได้ 1 อย่าง
- **แกน 3 บทส่งท้ายรายคน** (การ์ดท้ายเกมแบบ Monkey Island 2 / Fallout — นี่คือรางวัลของ plot ย่อย): ทุกตัวละครมีการ์ด 2–3 แบบตาม flag ของสายตัวเอง เช่น
  ลุง×ป้านก แต่ง/ไม่แต่ง, เก้า อยู่ซอย/กลับบริษัท/ไปเป็นดีเจสถานีเดียวที่เหลือ, คุณบีม ลาออก/ได้เลื่อนขั้น, ป้าจุ๋ม เปิดสำนักข่าว/ย้ายคอนโด, พี่เบิ้ม ได้โล่/โดนแฉ,
  ลุงหมอน้ำ ทำนายถูกครั้งแรกในชีวิต "ในวันที่ไม่มีใครฟัง", ช่างแดง กลับไปเฝ้าสถานี, เจ๊เกียว เผาสมุดหนี้/ขายต่อ, น้องเก่ง ได้ออกจากบ้าน
- **"ห้าดาว" สองความหมาย**: ตอนจบขาย = ห้าดาวจากแอปบริษัท (เดิม); ตอนจบที่ซอยรอด = ป้ายไม้เขียนมือที่ท่าเรือ "ไรเดอร์ห้าดาว ⭐⭐⭐⭐⭐ — ป้าจุ๋มให้" ชื่อเกมกลับความหมาย
- implementation: `Endings` (pure) → `outcome(flags)` = {decision, missing: [ปลุก/พา/ที่ไป], epilogues: {char: variant}}; flag `ally_*` คงไว้แต่ป้อนเข้าหมวด ไม่นับ
- **ฉากเรือ 3 เลน "ขบวนเรือตีสาม" — ใส่ แบบอลังการ (เจ้าของ 2026-10-02)**: หลังเปิดวาล์ว ไรเดอร์นำขบวนเรือทั้งซอยผ่านคลองใหญ่ตอนน้ำกำลังมา (`travel(dest, true)`):
  กลางคืน, เรือทุกลำที่หามาได้ตามหลัง (sprite ตัวละครที่ชวนได้นั่งอยู่จริง: ป้านกบนเรือก๋วยเตี๋ยวพ่วงแพ, พี่เปิ้ลกับวิน, กองเรือ LED พี่เบิ้มไลฟ์สด + โดรนบินตาม,
  พี่หนวดพาย), ระฆังวัดดังตลอด, ประทัดจากหอระฆัง, กำแพงน้ำ+ไอน้ำไล่หลังมาจากขอบจอ, ป้ายโครงการระยะที่ 14 ลอยผ่าน, หุ่นบริษัทบนแพโบกมือ.
  การชนมีผลจริง: ชน = เรือลำหลังสะดุด คนตก (ตัวละครนั้น "เปียก" ในการ์ดส่งท้าย ไม่ตาย), ชนครบ 3 = ขบวนล่าช้า → นับเป็นขาด "พา". ยาว ~60–90 วิ ไม่ข้าม
  (ฉากเดียวในเกมที่บังคับเรือ — ทุกฉากเดินทางอื่นยัง cutscene 3 วิ)
- ป้อมยามบท 3 = ประตูมีชีวิตตัวสุดท้าย (คุณบีม + หุ่น 2 ตัว): ผ่านด้วยปริศนาเท่านั้น (ชุดพนักงานจากลูกชายพี่เปิ้ล + บัตร 5 ดาวจากแบบสอบถาม)
- **ที่ทำจริง (2026-10-02)**: สายบท 3 เรียงตามนี้ — โทรโข่ง→ป้าจุ๋ม (ปลุก 1) · เก้า/ช่างแดง/เจ๊เกียว (ช่วย) · แหวน→ลุง = งานแต่ง (ที่ไป 1) · หน้าโต๊ะสาม→น้องบอย = ป้ายอนุญาต→หอระฆัง (ปลุก 2)
  · พี่เปิ้ลให้เสื้อวิน (พา 1) · เสื้อวิน→น้องต้น = ชุดยาม ผ่านหุ่น · บัตรห้าดาว + รายชื่อ→คุณบีม (ที่ไป 2) · การ์ดโดรน→พี่เบิ้ม (พา 2) · สมุดหนี้→ป้ายพยากรณ์ "ตีสี่" (เวลา)
  → กล่อง→เครื่องสูบ (คุณนายวรรณนับให้ถ้าขาด) → ขบวนเรือ 60 วิ (ชน = `wet_<คน>`) → งานแต่งรุ่งเช้า + ป้ายไม้ห้าดาว → การ์ดส่งท้าย 18 ใบ (`Endings.EPILOGUES`)

### 12.9 มุกต่อห้อง (รัฐบาล / น้ำท่วม / พยากรณ์) — prop แตะดูได้ ไม่หยิบ
- **ป้ายโครงการ** "แก้น้ำท่วมถาวร ระยะที่ 14" (ท่าเรือ) → ระยะที่ 15 (ตลาด) → 16 (วัด) ... เลขเพิ่มทุกห้อง, แผ่นสุดท้ายที่สถานี "ระยะที่ 1 (พ.ศ. 2561)"
- **เสาวัดระดับน้ำของรัฐ** (ประตูน้ำ): หน่วยเปลี่ยนทุกปี (ซม. → นิ้ว → "ระดับที่ยอมรับได้") ตัวเลขเลยไม่เคยขึ้น
- **แอปเตือนภัย** บนมือถือไรเดอร์: เตือน "น้ำท่วมซอยส่งไว" 3 วันหลังท่วม + ปุ่ม "ให้คะแนนการเตือน"
- **ถุงยังชีพ** (ชุมชนยกเสา): มาถึงวันที่น้ำลดพอดี ข้างในมีบะหมี่ + เทียน + ป้ายขอบคุณ ส.ส.
- **ประชาพิจารณ์** (ป้ายที่วินเรือ): "จัดบนเรือสำราญ ท่าเรือฝั่งตึก เวลา 10.00 (ตรงกับน้ำขึ้น ซอยออกไม่ได้)"
- **ศูนย์พักพิง** (คอนโด): ชั้นใต้ดิน
- **ป้ายพยากรณ์วันนี้** (ศาลา): "น้ำขึ้นแน่นอน (ยืนยันแล้ว 3 ครั้ง)" — เปลี่ยนทุกบท ผิดทุกบท
- **ศาลพระภูมิลอยน้ำ** (ชุมชนยกเสา มีแล้ว): ย้ายขึ้นทุ่นแล้วเทวดาเมาคลื่น
- **ตู้ ATM ของบริษัท** บนกำแพง: "ถอนได้เฉพาะดอกเบี้ย"
- **ป้าย "ห้ามจอดเรือบนดาดฟ้า"** (ตลาด), **"ไรเดอร์ห้ามใช้ลิฟต์"** (คอนโด — ลิฟต์อยู่ใต้น้ำ)

## 14. Redesign "สนุกมากๆ" (2026-10-03 — เจ้าของเล่นจบ: 5/10 เทียบ Monkey Island, "puzzle กระจัดกระจาย ไม่มีช่วง เย็ดเข้ เจ๋ง", "concept ตกค้างไม่มีผล เช่น สมุดหนี้") **[ร่าง รอเจ้าของเลือก]**

### 14.1 วินิจฉัย — ทำไมได้ 5
1. **ปริศนา 80% = fetch quest** (เอาของ A ไปให้คน B ที่บอกว่าอยากได้ A) — ไม่มีอะไรให้ "คิดออก" เฉลยไม่ทำให้หัวเราะ ผู้เล่นแค่ขนของ
2. **เฉลยไม่ใช่มุก** — MI: ไก่ยางมีรอก, เหล้า grog ละลายแก้ว, ด่ากันแทนฟันดาบ = กลไกคือ punchline. ของเรา: ประทัดทำให้หุ่นหัน (ตรงไปตรงมา), เชือกซ่อมระฆัง (งานช่าง)
3. **กระจัดกระจาย**: 15 ห้อง ของ 40 ชิ้นใช้ชิ้นละครั้ง เดินทางบ่อย เป้าหมายใหญ่ไม่อยู่ตรงหน้า (รู้แค่ "ไปคุยคนต่อไป")
4. **concept ตกค้างที่ไม่มีผลกับการเล่น** (ทำให้งง): สมุดหนี้ (ไอคอน+เมนู แต่ไม่ใช่กลไก), "หนี้" (เรื่อง ไม่ใช่ตัวเลข ไม่มีผล), น้ำขึ้นลง (ใช้ 2 ครั้ง ไม่รู้ว่าทำไมมี), โซนจับของหุ่น (เป็นฉาก), ของหลอก, การ์ดส่งท้าย, แผนที่ (= เมนู)
5. **ไม่มีกลไกที่ใช้ซ้ำแบบยกระดับ** — ทุกปริศนาเป็น one-off เลยไม่มีช่วง "อ๋อ! ใช้อันเดิมได้แบบนี้ด้วย"

### 14.3 แก่นเรื่องใหม่: **"เมืองที่เชื่อกระดาษมากกว่าน้ำ"**
กรุงเทพฯ 2090 ไม่มีใครดูของจริงแล้ว ทุกคน (และหุ่นทุกตัว) ทำตาม**ตัวหนังสือ**: ป้ายส่ง สมุดหนี้ พยากรณ์ ป้ายราชการ — ไรเดอร์ไม่มีเงิน ไม่มีอำนาจ แต่มี**ปากกา**.
กลไกหลักของเกมคือ "การเขียน" 3 แบบ ใช้ทั้ง 3 ทุกบท ยากขึ้นทุกครั้ง และด่านใหญ่ท้ายบทต้องต่อกัน:

| verb | ของ/ที่ | กฎของโลก (สอนครั้งเดียวต้นเกม แล้วใช้ตลอด) | UI |
|---|---|---|---|
| **ส่ง** | ป้ายส่งไว (ของในกระเป๋า มีใบเดียว ได้คืนเมื่อส่งถึง) | ติดป้ายกับ**อะไรก็ได้** (ของ สัตว์ คน หุ่น ตัวเอง) = กลายเป็นพัสดุ → พัสดุต้องเดินตามไรเดอร์ → **ผู้รับต้องรับ** (ไม่งั้นโดน 1 ดาว) → ห้ามเปิดดู | ใช้ป้ายกับสิ่งนั้น → เลือกผู้รับจากรายชื่อในสมุดหนี้ (ทุกคนที่รู้จัก) |
| **เซ็น** | สมุดหนี้ | อะไรที่มีลายเซ็นในสมุดหนี้ = ศักดิ์สิทธิ์ ต้องทำตาม: **จด**คำสัญญาที่คนเผลอพูด (เกมจดให้อัตโนมัติ มี notice) → **ยื่นให้เซ็น** / **โอนหนี้** (ยกหนี้ให้คนอื่น หรือรับหนี้คนอื่น) | ใช้สมุดกับคน → เลือกหน้า |
| **ป้อน** | ลุงหมอน้ำ (ศาลา) + ตู้รับเรื่องหน้าศาลา | ลุง**ลอก**ทุกกระดาษที่ดูเป็นทางการมาประกาศเป็นพยากรณ์ของตัวเอง และ**บริษัททำตามพยากรณ์ของลุงเป็นระเบียบ** (เปิด/ปิดท่อ = น้ำขึ้นลงในซอย, หุ่นเฝ้า/กลับฐาน, เวลาเปิดท่อ) → ผู้เล่นเขียนกระดาษใส่ตู้ = คุมบริษัทผ่านคนที่ไม่รู้ตัวว่าถูกใช้ | เขียนกระดาษ (เลือกข้อความที่ปลดล็อก) → ใส่ตู้รับเรื่อง → ลุงประกาศ → โลกเปลี่ยน |

- **หนี้เป็นตัวเลขบนจอ** (มุมซ้ายบน ข้างน้ำขึ้นลง): เริ่ม 30,000 **มีแต่ขึ้น** ทุกอย่างในเกมเพิ่มหนี้ (ค่าส่งถึงตัวเอง +20, ดอกเจ๊เกียวทุกครั้งที่คุย, รับหนี้ลุง 40 ปี +1,200,000) จนตอนจบ**ส่งหนี้ทั้งก้อนเป็นพัสดุให้บริษัท** → 0
- ตัดทิ้ง: โซนจับ/การผลักของหุ่น (หุ่น = prop + บทพูด, ด่านทุกด่านเป็นกฎในข้อมูล), ของหลอกหยิบได้ (เหลือ 1: พระเครื่องกันน้ำ), การรอน้ำที่ม้านั่ง (น้ำคุมด้วยคำทาย), ห้อง condo/cat_roof/boat_rank (รวมเข้าห้องอื่น)
- คง: ตอนจบเดียว + ขบวนเรือ + การ์ดส่งท้าย, แผนที่, UI สมุด/กระดาษ/ป้ายสังกะสี, hint 3 ขั้นทุกเรื่อง, backdrop/prop/ตัวละครที่มี

### 14.3b ลุงหมอน้ำ (เจ้าของ 2026-10-03: ต้นแบบคือ "คนเหี้ยที่คนบูชา — ทายถูกเรื่องใหญ่เรื่องเดียว นิสัยคือลอกงานคนอื่น ลบที่ทายผิด แก้ย้อนหลังให้แม่นขึ้น")
- **ประวัติ**: ทายน้ำท่วมใหญ่ 2060 ถูกครั้งเดียว (จริงๆ ลอกจากประกาศเขตที่ไม่มีใครอ่าน) → ทั้งซอยบูชา มี**ศาลหมอน้ำ**หน้าศาลา ชาวบ้านเอาของมาถวาย (ป้าจุ๋มเชื่อสุดใจ น้องเก่งไม่เชื่อแต่ไม่กล้าพูด)
- **ป้ายพยากรณ์ "แม่น 100%"**: ผนังศาลาเต็มไปด้วยพยากรณ์ 30 ปี ถูกทุกแผ่น — เพราะ**ลุงลบแล้วเขียนใหม่ทุกคืนหลังรู้ผล** (ร่องรอยลบ/กระดาษซ้อน/หมึกสองสี = มุกที่ผู้เล่นค่อยๆ สังเกต) ผู้เล่นทำอะไรสำเร็จ รุ่งขึ้นป้ายเขียนว่า "ลุงทายไว้แล้ว"
- **ไม่เคยทายเอง**: ทายได้ต่อเมื่อมี "ข้อมูลประกอบ" (= กระดาษให้ลอก) จาก**ตู้รับเรื่อง**หน้าศาลา — บริษัทเลิกส่งตารางมานานแล้ว ลุงเลยตัน; ปลาทองในโหลเป็นแค่พิธี (ของโชว์ให้คนถวาย) → **ผู้เล่นคือ "แหล่งข่าว" คนใหม่ของลุง** โดยลุงไม่รู้ และบริษัททำตามลุงเพราะเชื่อว่าแม่น 100%
- **ลอกงานคนอื่น**: ชื่อผู้เล่น/ป้าจุ๋ม/น้องเก่ง ไม่เคยถูกเอ่ย — ทุกเรื่องกลายเป็น "ลุงเห็นมาก่อน"; ตอนคุณบีมถาม ลุงเอาสมุดหนี้ของไรเดอร์ไปอ่านแล้วอ้างว่า "ลุงเตือนไว้แล้ว"
- **นิสัยในบทพูด**: ไม่น่าคบ หยิ่ง สบประมาท เรียกไรเดอร์ว่า "ไอ้หนูส่งของ" ขอของถวายก่อนคุย ไม่เคยขอโทษ — แต่เกมไม่ลงโทษเขา (satire): การ์ดส่งท้าย = ศาลใหญ่ขึ้น "ผู้ทำนายคืนตีสาม" ทั้งที่หนีไปอยู่ตึกบริษัทตั้งแต่สี่ทุ่ม
- **บท 3**: ลุงหนีก่อนใคร (เอาของถวายไปด้วย) → ไม่มีคนประกาศ → ผู้เล่นต้อง**ลอกลายมือลุง**เขียนป้าย "ตีสี่" เอง = ผู้เล่นกลายเป็นหมอน้ำ (และลุงจะมาเคลมทีหลัง)
- สิ่งที่ตัดจากร่างก่อน: กลไก "ทายผิดเป๊ะทุกครั้ง/ทำตรงข้าม" (เข้าใจยากกว่าและไม่ตรงต้นแบบ) → แทนด้วย "ป้อน": เขียนอะไรให้ลุงลอก บริษัทก็ทำตามนั้นตรงๆ

### 14.4 ทำไม "ป้ายส่งไว" แทนดวลด่า
- original: ไม่มีเกมไหนให้ "ส่งคน" — และมันคือตัวตนของตัวเอก (ไรเดอร์ส่งของ) ไม่ใช่กลไกยืมจากโจรสลัด
- ทุกการใช้มีภาพตลกในตัว: พี่หนวดเดินตามหลังไรเดอร์พร้อมป้ายส่งแปะหน้าผาก, แมวเดินตามแบบไม่เต็มใจ, ไรเดอร์ติดป้ายตัวเองเข้าป้อมยาม, หุ่นบริษัท "ส่งคืนบริษัท"
- ยกระดับได้: บท 1 ส่งของ/สัตว์ → บท 2 ส่งตัวเอง/ส่งคน → บท 3 ส่ง "หนี้" (นามธรรม) ให้บริษัท = punchline ของทั้งเกม

| # | ปริศนา | punchline | กลไก (ทำยังไง) | สอนอะไร |
|---|---|---|---|---|
| 1.1 | กุญแจเรือตกร่องพื้น | ส่งปลาตะเพียนที่คาบกุญแจ**ถึงตัวเอง** ค่าส่ง +20 เข้าหนี้ | ป้ายส่ง → ร่องพื้น ("ติดกับร่องไม่ได้ ติดกับปลาได้") → ผู้รับ: ตัวเอง → ปลากระโดดเข้ากระเป๋าพร้อมกุญแจ | ส่ง: ติดอะไรก็ได้ + ส่งถึงตัวเอง |
| 1.2 | พี่หนวดเฝ้าเรือเตอร์ไซค์ | ติดป้ายส่งพี่หนวด จ่าหน้า "เจ๊เกียว (ของคืน)" — พี่หนวดต้องเดินตามไรเดอร์ขึ้นเรือไปแพเจ๊เกียว เจ๊เกียวต้องเซ็นรับ "ไม่ได้สั่ง!" | ป้ายส่ง → พี่หนวด → ผู้รับ: เจ๊เกียว (ชื่อหน้าแรกในสมุดหนี้) → พี่หนวดเดินตาม (ท่าเรือว่าง เสียบกุญแจได้) → นั่งท้ายเรือไปแพ → ส่ง → ป้ายคืน | ส่งคน + รายชื่อผู้รับ = สมุดหนี้ |
| 1.3 | ป้านกให้กล่องเฉพาะ "ลูกหนี้ตัวจริง" (คนฝากสั่งไว้: ให้คนที่ติดหนี้เยอะที่สุดในซอย) | เพื่อให้ได้ค่าจ้างล้างหนี้ ต้อง**เป็นหนี้มากขึ้น**: รับโอนหนี้ก๋วยเตี๋ยว 40 ปีของลุงโต๊ะสาม (1,200,000) ลุงเซ็นให้ทันทีด้วยความยินดี | ยื่นสมุดให้ป้านก (ตะโกน/เขียนตัวโต) → "30,020 น้อยไป ลุงโต๊ะสามติดป้ามากกว่า" → สมุด → ลุง → "รับโอนหนี้" → ลุงเซ็น → ยื่นสมุดให้ป้านกอีกที → กล่อง | เซ็น: โอนหนี้ |
| 1.4 | บ้านเลขที่ 0 อยู่ไหน (ไม่มีในแผนที่ ไม่มีใครรู้) | ลุงหมอน้ำ "ทายไว้แล้วตั้งแต่ 2060" แต่ต้นฉบับอยู่ใน**กล่องห้ามเปิด**ใต้ศาล (ที่ลุงเก็บของที่ลบไปทั้งหมด) → "ห้ามเปิด แต่ไม่ได้ห้ามส่ง": ติดป้ายส่งกล่องถึงตัวเอง → ในกล่อง: ประกาศเขต 2060 ที่ลุงลอก "สถานีสูบน้ำ บ้านเลขที่ 0 ใต้สะพาน" + พยากรณ์ผิด 29 ปีที่ถูกลบ | ศาลา: ผนัง "แม่น 100%" มีรอยลบ → ลุงไม่บอก ("ไอ้หนูส่งของ ถวายของก่อน") → กล่องใต้ศาล → ป้ายส่ง → ตัวเอง → ประตูน้ำปลดล็อก + ป้าจุ๋มรับข่าว "ลุงลบพยากรณ์" (ป้าไม่เชื่อ: "ลุงไม่มีวันลบ") | ส่ง + รู้จักลุงตัวจริง |
| 1.5 | ประตูน้ำจมอยู่ (น้ำขึ้น) และหุ่นรุ่นเก่าเฝ้าประตู "ตามพยากรณ์น้ำขึ้น กันคนเปิดประตูตอนน้ำมา" | **กระดาษใบเดียวแก้สองอย่าง**: ใส่ตู้รับเรื่อง "พยากรณ์: น้ำลง (ยืนยัน)" → ลุงลอกประกาศ → บริษัทปิดท่อตามลุง น้ำลง ประตูโผล่ **และ**หุ่นอ่านพยากรณ์ "น้ำลง" = กลับฐาน; รุ่งขึ้นผนังศาลา: "ลุงทายน้ำลงไว้แล้ว" | ปลดล็อกข้อความ "น้ำลง" เมื่อรู้ว่าลุงลอก (1.4) + ลุงต้องมีปลาทองทำพิธีถึงยอมประกาศ (1.7) → เขียนกระดาษ → ตู้ → old_gate เปลี่ยน | ป้อน ≫ ลุง ≫ บริษัท ≫ น้ำ+หุ่น (ด่านใหญ่บท 1) |
| 1.6 | ช่างแดงซ่อนใต้เรือคว่ำ เพราะหุ่นเบอร์ 9 หันหน้าตามคนตลอด (ฟิวส์อยู่ข้างหลัง) | ป้ายใหม่ของน้องบอย: **"มารยาท: ห้ามหุ่นหันหน้าหาลูกค้า"** → เบอร์ 9 หันหลังให้ทุกคนตลอดไป ดึงฟิวส์สบาย | น้องบอยติดป้าย "ระยะที่ 14" ที่อู่ ขอแผ่นเปล่า → ไรเดอร์เขียน (เลือกข้อความ 3 ตัวเลือก มุกทุกอัน) → ติดที่อู่ → ดึงฟิวส์ → ช่างแดงออกมา ให้มือหมุน (หัก) + เทป → ผสม | ป้าย: เขียนกฎให้โลก |
| 1.7 | ลุงไม่ยอมประกาศถ้าไม่ได้ทำพิธีหน้าโหลปลาทอง (พิธีคือของโชว์ ปลาไม่เกี่ยวอะไรเลย) — ปลาหาย แมวส้มโอขโมยไปหลังคาตลาด | ติดป้ายส่ง**แมว** จ่าหน้า "ลุงปลาทู (แมวที่ขโมยปลา)" — แมวเดินตามแบบไม่เต็มใจ ลุงปลาทูต้องรับ "ผมไม่ได้ขอให้เอาแมวมา ขอให้จับ!" "จับแล้วส่งครับ" | ที่ตลาด แมวโผล่บนหลังคา → ป้ายส่ง → แมว → ผู้รับ: ลุงปลาทู → กองสมบัติไม่มีแมวเฝ้า → ปลาทอง (+ ที่ม้วนผมป้าจุ๋ม = ข่าว) | ส่งสัตว์ |
| 1.8 | มือหมุนหักต้องซ่อม / ประตูเหล็กฝืด | ช่างแดง: "เทปพันสายไฟซ่อมได้ทุกอย่าง ยกเว้นหนี้" | ผสม (คง) → ใช้กับประตูตอนน้ำลง (หลัง 1.5) | ของผสม |
| 1.9 | **จบบท**: กล่องถึงบ้านเลขที่ 0 แต่ไม่มีผู้รับ | แอป: "ส่งไม่ได้ ผู้รับไม่มีตัวตน ... ค่าส่งไม่จ่าย หนี้ยังอยู่ (1,230,040)" กล่องพูด: "อย่าเพิ่งเสียบ" | ใส่กล่องในช่อง → การ์ดจบบท | hook บท 2 |

| 2.1 | เจ๊เกียวขายหนี้ทั้งซอยไปแล้ว "ถามหุ่น" — หุ่นเบอร์ 9 ฟิวส์ขาด จำอะไรไม่ได้ | ตั้งชื่อหุ่นด้วยสมุดหนี้ ("เก้า") → หุ่นมีชื่อ = เป็นคนตามกฎซอย = **ติดหนี้ได้** → ไรเดอร์โอนหนี้ให้เก้า 100 บาท → เก้าต้องตามใช้หนี้ = ให้ชิปความจำ | สมุด → หุ่น → "ตั้งชื่อ" → โอนหนี้ → ชิป (คง+ยกระดับ) |

| 2.5 | (ไม่บังคับ) จดหมายรัก 30 ปีของลุง ป.ล. "ตีสามบริษัทเปิดท่อ" | ป้านกอ่านไม่ได้ แว่นตกน้ำ → แว่นป้าจุ๋ม (2.3) → ป้านกตอบ "แล้วแหวนล่ะ" | คง = plot ย่อยสำหรับการ์ดส่งท้าย + หลักฐาน 2 ทางเลือก |

| 2.7 | คุณหญิงลออ (บ้านติดป้าจุ๋ม) สั่งของจากแอปทุกวันทั้งที่ลิฟต์จม — ไรเดอร์คนเดียวที่มาถึง | ของหลอก/มุก: ส่งพัสดุให้คุณหญิง = ได้ 5 ดาวครั้งแรกในชีวิต ... จากคนที่สั่งน้ำแข็งตอนน้ำท่วม | ป้ายส่ง → ของอะไรก็ได้ → คุณหญิง (การ์ดส่งท้าย) |

| 3.5 | **ด่านสุดท้าย**: หุ่นบริษัททั้งฝูงมาที่สถานีตอนบิดวาล์ว + หนี้ 1,230,040 ยังอยู่ | **ติดป้ายส่ง "หนี้"** (หน้าสมุดทั้งเล่ม) จ่าหน้า "บจ.ป้องกันภัย" → ผู้รับต้องรับ → บริษัทรับหนี้ทั้งซอย → หุ่นทุกตัวอ่านสมุด: เจ้าหนี้ = บริษัท ลูกหนี้ = บริษัท → "ข้อผิดพลาด ... ทวงตัวเอง" เดินวนทวงกันเอง → หนี้บนจอ = 0 | ส่ง+เซ็น+ทาย ต่อกัน (ส่งหนี้ได้เพราะหนี้ "มีชื่อผู้รับ" จากรายชื่อ 2.6) |
| 3.6 | ขบวนเรือตีสาม → งานแต่งรุ่งเช้า → ป้ายไม้ห้าดาว → การ์ดส่งท้าย | (คง) + แอปส่งไวแจ้งเตือนสุดท้าย: "ส่งสำเร็จ 1 รายการ: หนี้ 1,230,040 ถึงผู้รับแล้ว ให้คะแนนการส่ง?" ⭐⭐⭐⭐⭐ | — |

### 14.10 จังหวะ "เย็ดเข้" ที่ตั้งใจ (ต้องถึงทั้ง 3)

2. กลางบท 2: กระดาษปลอม "เปิดท่อตีสาม" ได้หลักฐานจริงจากกล้องที่ไม่มีใครดู

### 14.12 แก้ตามคำติ (เจ้าของ 2026-10-03: "ป้ายมันดูง่ายไปไหม และซ้ำซาก")
**ปัญหา**: ป้ายส่ง = ใช้กับ X แล้วเลือกผู้รับจากรายการ → เป็นเมนู ไม่ใช่ปริศนา; ใช้ 7 ครั้งแบบเดียวกัน. เขียนป้าย/ป้อนลุง = "เลือกข้อความ 3 ตัวเลือก" ก็เมนูเหมือนกัน

**แก้ 1 — กฎ "ติดป้ายส่งได้เฉพาะสิ่งที่มีเจ้าหนี้"** (ของ/คน/หุ่น/ตัวเอง ต้องมีคนที่มันเป็นหนี้อยู่ แอปถึงถือว่าเป็น "ทรัพย์สิน" ส่งได้ — มุกมืดที่ตรงธีม)
→ การส่งแต่ละครั้งต้อง**หาหรือสร้างหนี้ก่อน** ด้วยสมุด = สองกลไกต่อกัน ไม่ใช่กดเมนู และผู้รับที่ถูกต้องคือ "เจ้าหนี้" หรือ "คนที่สั่ง" — ส่งผิดคน = ผู้รับปฏิเสธ (มุก + ป้ายคืน)
| ครั้ง | ส่งอะไร | ต้องรู้/ทำอะไรก่อน (ส่วนที่ต้องคิด) | ทำไมไม่ซ้ำ |
|---|---|---|---|
| 1.1 ปลาตะเพียน | สัตว์ | สอนกฎ: ปลา "ติดหนี้" ค่าเช่าร่องพื้นกับเจ้าของห้อง = ไรเดอร์ → ส่งถึงตัวเอง | tutorial |
| 1.2 พี่หนวด | คน | ต้องรู้ว่าพี่หนวดเองก็เป็นลูกหนี้เจ๊เกียว (ป้าจุ๋มขายข่าวนี้ / หน้าสมุดเจ๊เกียวที่พี่หนวดทำหล่น) ไม่งั้นแอปไม่รับ "คนไม่ใช่ของ" | ต้องสืบก่อน |
| 2.2 ตัวเอง | ตัวเอง | ตัวเองเป็นลูกหนี้อยู่แล้ว (1.2 ล้าน!) — แต่ผู้รับต้องเป็นคนที่ "สั่ง" → ต้องทำให้บีม**สั่งไรเดอร์**ก่อน: แบบสอบถามบีมมีช่อง "ต้องการให้ไรเดอร์มาพบ?" ติ๊ก 5 ดาว | พลิก: ผู้รับต้องสั่ง |
| 3.3 หุ่นบริษัท | เครื่องจักร | หุ่นไม่มีหนี้ → **สร้างหนี้ให้มัน**ด้วยสมุด (ตั้งชื่อ + โอนหนี้ 1 บาท เหมือนที่ทำกับเก้าในบท 2 — ผู้เล่นต้องนึกออกเองว่าใช้ซ้ำได้) แล้วส่งคืน "เจ้าของ" = บริษัท | สองกลไกต่อกัน |
| 3.5 หนี้ | นามธรรม | หนี้ทั้งซอยมี "เจ้าของ" = บริษัท (รายชื่อ 2.6) → ส่งหนี้คืนเจ้าของ | punchline ทั้งเกม |
| ~~1.7 แมว~~ | — | **แมวเป็นสิ่งเดียวในเมืองที่ไม่เชื่อกระดาษ** ติดป้ายไม่ติด (มุก) → ล่อด้วยปลาทูแบบเดิม | ข้อยกเว้นที่เป็นมุก |
| ~~3.2 น้องต้น~~ | — | เปลี่ยนเป็น "ป้อน": ประกาศ "บริษัทให้ยามหยุดคืนนี้" → ต้นกลับบ้านเอง | ลดการส่งคนซ้ำ |
→ ส่งเหลือ 5 ครั้ง ห่างกัน แต่ละครั้งเป็นชนิดใหม่ (สัตว์ → คน → ตัวเอง → หุ่น → นามธรรม) และต้องแก้โจทย์ย่อยก่อนทุกครั้ง

**แก้ 2 — "เขียน" = ประกอบจากชิ้นส่วนข้อความที่เก็บมา ไม่ใช่เลือกจาก 3 ตัวเลือก**
- ผู้เล่นเก็บ**วลี**จากป้าย/เอกสาร/คำพูดในซอย (จดลงสมุดอัตโนมัติเมื่อแตะดู): "ห้าม", "หุ่นทุกตัว", "หันหน้าหาลูกค้า", "ตามระเบียบ", "ยืนยันแล้ว", "น้ำลง", "เปิดท่อ 03:00", "ขอบคุณที่เป็นแก้มลิง", "ระยะที่ 14" ...
- เขียน = เลือกวลี 2–3 ชิ้นต่อกันบนกระดาษ (UI กระดาษโน้ต + ตราประทับ) แล้วเอาไปใช้ 3 ช่องทาง: **ป้าย** (หุ่นทำตามตัวอักษร) / **ตู้ลุง** (ลุงลอกเฉพาะที่มี "ยืนยันแล้ว"/ตราเขต) / **สมุด** (คำสัญญาให้เซ็น)
- ประกอบผิดก็มีผล (ไม่ใช่แค่ "ไม่ได้"): "ห้าม + หุ่นทุกตัว + หันหน้าหาลูกค้า" = เบอร์ 9 หันหลัง ✓; "ห้าม + ลูกค้า + หันหน้าหาหุ่น" = ไรเดอร์โดนหุ่นสั่งให้หันหลัง (มุก); "หุ่นทุกตัว + กลับฐาน" ที่ป้อมยาม = หุ่นกลับฐานจริงแต่พาบีมไปด้วย
- วลีเป็นของสะสมตลอดเกม ใช้ซ้ำข้ามบท (วลี "ขอบคุณที่เป็นแก้มลิง" จากโบรชัวร์บท 2 กลายเป็นสัญญาของบีมบท 3) = กลไกเดียว ความลึกมาจากชุดวลีที่โตขึ้น
- จำนวนช่องวลีจำกัด (กระดาษ 3 ช่อง) + ตราประทับของเขตมีจำกัด (น้องบอยให้ 1 ดวงต่อการช่วยติดป้าย) = ต้องเลือก

**ผลต่อจำนวนกลไก**: เหลือ 2 verb ใหญ่ — **ส่ง** (5 ครั้ง มีเงื่อนไขหนี้) และ **เขียน** (ประกอบวลี → ป้าย/ตู้/สมุด) — สมุดหนี้คือที่เก็บทั้งวลี หนี้ และคำสัญญา (ของชิ้นเดียวที่เปิดดูได้ตลอด) ส่วนลุงหมอน้ำคือ "เครื่องขยายเสียง" ของกระดาษ
